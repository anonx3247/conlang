## What Was Built

### Task 1: Construction Resolution Engine (TDD)

**paradigm_engine_construction_test.dart** — Wave 0 skip-annotated stubs replaced with 14 concrete TDD tests across 4 groups:

- **construction resolution (4 tests):** base form wrapping, D-04 inflectional composition, CellFormReference cross-cell resolution, D-04 + cross-cell combined
- **cycle detection D-09 (4 tests):** direct self-loop, indirect A→B→A, three-node A→B→C→A, valid chain (no cycle)
- **construction rule specificity and binding (3 tests):** most-specific rule wins, no-match fallthrough to inflectional result, inactive rule skipped
- **token assembly D-112 (3 tests):** ParticleToken/WordSlotToken type verification, form = space-joined IPA, phonemic = space-joined phonemic

**paradigm_engine.dart** gained `resolveConstructionCell` function (and helpers):

- **`resolveConstructionCell`**: entry point. Finds most-specific active matching rule, checks `resolvingStack` for cycle, adds target key to stack, resolves word slot form via switch on `FormReference`, assembles tokens, stores in `resolvedCache`, removes from stack in `finally`.
- **`_cellToWordForm`**: extracts `(ipa, phonemic)` from any `ParadigmCell` subtype; falls back to root for uncovered/ambiguous/unresolvable cells.
- **`_assembleTokens`**: iterates sorted slots, creates `ParticleToken` for `gloss_tag` slots (case-insensitive glossTag match), `WordSlotToken` for the designated word slot id; silently skips unmatched gloss_tag slots (T-10.1-05).
- **`_featureSetKey`**: sorted canonical string key for FeatureSet (keeps paradigm_engine.dart self-contained — no import of typology_providers.dart).
- **`_buildCyclePath`**: formats `Set<String> stack + newKey` into `"Cell {k1} → Cell {k2} → ..."` for `ParadigmUnresolvable.cyclePath`.

Key algorithmic detail for cycle propagation: when `CellFormReference` recursively calls `resolveConstructionCell` and receives `ParadigmUnresolvable`, the outer call stores the cycle result in `resolvedCache[targetKey]` and returns it immediately — bypassing token assembly. This ensures multi-hop cycles (A→B→C→A) are correctly detected and propagated.

### Task 2: Provider Wiring

**typology_providers.dart** extended with:

1. **`generateParadigm` new optional params** (backward compatible with `const []`/`const {}` defaults):
   - `List<ConstructionRule> constructionRules = const []`
   - `List<Lexeme> closedClassWords = const []`
   - `Map<int, List<ConstructionSlot>> constructionSlotsByConstructionId = const {}`

2. **Construction post-pass** inside `generateParadigm` — runs only when `constructionRules.isNotEmpty`. Iterates all entries, calls `resolveConstructionCell` per cell (with shared `resolvingStack`/`resolvedCache`), replaces entries where the result differs from the inflectional cell.

3. **`computedInflectedParadigmProvider` wiring**:
   - Watches `constructionRulesForPosProvider(pos.id)` → construction rules scoped to the lexeme's POS
   - Watches `closedClassLexemeListProvider` → all closed-class words (particles, auxiliaries, etc.)
   - Builds `constructionSlotsByConstructionId` by watching `constructionSlotsProvider(rule.constructionId)` for each unique construction id in active rules
   - Passes all three to `generateParadigm`

4. **New imports**: `construction_rule.dart`, `construction_providers.dart`, `construction_rule_providers.dart`, `particle_providers.dart`

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Cycle propagation failure in initial implementation**
- **Found during:** Task 1 GREEN phase — direct self-loop test returned `ParadigmConstructionFilled` instead of `ParadigmUnresolvable`
- **Issue:** Original design extracted word slot resolution into `_resolveWordSlotForm` returning `(String, String)`. When recursive `resolveConstructionCell` returned `ParadigmUnresolvable`, `_cellToWordForm` silently degraded it to `(root, root)`, so the cycle was never propagated back to the outer call.
- **Fix:** Inlined word slot resolution logic into `resolveConstructionCell` using a `switch` on `FormReference`. The switch arm for `CellFormReference` now checks `if (resolved is ParadigmUnresolvable)` immediately after the recursive call and returns the cycle result before token assembly.
- **Files modified:** `lib/features/grammar/domain/paradigm_engine.dart`
- **Commit:** 4b75c94 (cycle fix integrated into same commit)
