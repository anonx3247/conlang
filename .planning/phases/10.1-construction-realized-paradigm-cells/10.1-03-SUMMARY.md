**One-liner:** RuleEditorDialog extended with `existingConstructionRule` param, RuleEditorBody gains three-picker construction form (construction picker + word slot selector + RadioGroup form reference), and InflectionalRulesPage shows construction rules section with CRUD access.

## What Was Built

### Task 1: RuleEditorDialog + RuleEditorBody Construction Variant

**rule_editor_dialog.dart:**

- Added `final ConstructionRule? existingConstructionRule` parameter
- Passes `existingConstructionRule` down to `RuleEditorBody`
- Import added for `construction_rule.dart`

**rule_editor_body.dart:**

- Added `existingConstructionRule: ConstructionRule?` parameter to widget
- Construction form state variables: `_selectedConstructionId`, `_selectedWordSlotId`, `_formReference`, `_editingConstructionRule`, `_selectedCellRefJson`, `_cellRefModeActive`
- `initState` hydrates all construction state from `existingConstructionRule` including POS bindings and feature bindings from the existing rule's `bindings` field
- `_buildConstructionForm` method — full construction form layout:
  - **Rule name** `TextField`
  - **POS + feature binding chips** — reuses `InflectionalTopSection` verbatim (identical to inflectional mode)
  - **Construction picker** — `DropdownButtonFormField<int>` watching `constructionListProvider`; empty state shows UI-SPEC hint text "No constructions defined. Add one in Grammar → Constructions."
  - **Word slot picker** — `DropdownButtonFormField<int>` watching `constructionSlotsProvider(_selectedConstructionId!)`; auto-selects first `pos` slot via `addPostFrameCallback`
  - **Form reference picker** — `RadioGroup<bool>` with `RadioListTile` for "Base (uninflected) form" and "Reference another cell"
  - **Cell cross-reference dropdown** — shown when `_cellRefModeActive` is true; lists all `{DimName}: {LevelName}` combinations for the selected POS by watching `dimensionsForPosProvider`
- `_saveConstructionRule` method handles insert + `setPosLinks` (create) and `updateRule` + `setPosLinks` (update) via `constructionRuleDaoProvider`
- Delete button (`Icons.delete_outline`) shown when editing; calls `dao.deleteRule` immediately (no confirm dialog per UI-SPEC)

### Task 2: InflectionalRulesPage — Construction Rules Section

**inflectional_rules_page.dart** converted from `StatelessWidget` to `ConsumerWidget`:

- Optional `posId` parameter added for POS scoping
- Watches `constructionRulesForPosProvider(posId!)` when `posId` is set
- `_ConstructionRulesSection` widget appended below the `RulesPage(kind: inflectional)`:
  - Section header "CONSTRUCTION RULES" + "New Construction Rule" `TextButton.icon`
  - `New Construction Rule` opens `RuleEditorDialog(kind: RuleKind.construction)`
  - `_ConstructionRuleCard` per rule: `Icons.account_tree_outlined` badge (D-10), rule name, tap → `RuleEditorDialog(existingConstructionRule: rule)`
  - Empty state: "No construction rules for this POS. Click a paradigm cell or use New Rule."

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] RadioListTile deprecated API**
- **Found during:** Task 1 — dart analyze
- **Issue:** `RadioListTile.groupValue` and `RadioListTile.onChanged` are deprecated since Flutter 3.32. Plan specified `RadioListTile` but didn't account for the new `RadioGroup` API.
- **Fix:** Wrapped `RadioListTile` widgets in a `RadioGroup<bool>` parent widget. `_cellRefModeActive` boolean introduced to track radio group state (needed because `_formReference` is a sealed type that only becomes `CellFormReference` after a cell is explicitly chosen from the nested dropdown).
- **Files modified:** `rule_editor_body.dart`
- **Commit:** ea9ea76

**2. [Rule 2 - Missing] Hydrate POS bindings from existingConstructionRule**
- **Found during:** Task 1 — reviewing `initState` logic
- **Issue:** Plan specified hydrating name, constructionId, wordSlotId, formReference — but not the POS set and feature bindings from `existingConstructionRule.bindings`. Without this, editing an existing rule would show all chips unselected.
- **Fix:** Added `_inflectionalPosSet.addAll(existingConstructionRule.bindings.pos)` and `_featureBindings.addAll(existingConstructionRule.bindings.dims)` to the hydration block.
- **Files modified:** `rule_editor_body.dart`
- **Commit:** ea9ea76

**3. [Rule 2 - Missing] navigator captured before await in delete handler**
- **Found during:** Task 1 — dart analyze
- **Issue:** `use_build_context_synchronously` lint: `Navigator.of(context).pop()` used after `await dao.deleteRule(...)` without capturing navigator first.
- **Fix:** Captured `Navigator.of(context)` into `navigator` local variable before the await, then called `navigator.pop()` after.
- **Files modified:** `rule_editor_body.dart`
- **Commit:** ea9ea76
