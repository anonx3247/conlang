## What Was Built

### Task 1: Domain Models

**paradigm_cell.dart** gained two new sealed variants:

- `ParadigmConstructionFilled` — holds `List<ConstructionToken> tokens`, `String form` (space-joined IPA, post-rewrite), `String phonemic` (space-joined phonemic, pre-rewrite), `String constructionName`. Constructor auto-computes `form` and `phonemic` from tokens when not explicitly provided.
- `ParadigmUnresolvable` — first-class cycle state with `String cyclePath` (e.g. `"Cell FUT → Cell COND → Cell FUT"`). No exception thrown — sealed hierarchy handles it.

**construction_rule.dart** (new file):

- `ConstructionToken` sealed class with `ParticleToken` (ipa, optional romanization) and `WordSlotToken` (ipa + phonemic per D-112 invariant)
- `FormReference` sealed class with `BaseFormReference` (base/uninflected form) and `CellFormReference` (cross-cell reference via `targetFeatureSet`). `FormReference.fromJson` is defensively parsed — malformed JSON → `BaseFormReference` (T-10.1-01 mitigation)
- `ConstructionRule` domain model with `FeatureBindings bindings` reuse (D-01), `int get specificity => bindings.specificity`, and `ConstructionRule.fromDbRow(dynamic row)` factory

**rule_kind.dart** extended with `RuleKind.construction` value. `fromDbString` handles `'construction'` case. `dbString` getter updated.

### Task 2: Schema v16, DAO, Providers

**app_database.dart:**
- `ConstructionRules` table: id, name, isActive, ordering, constructionId (FK → PhraseConstructions), wordSlotId (FK → ConstructionSlots), formReferenceJson, featureBindings (via FeatureBindingsConverter)
- `ConstructionRulePOS` junction table with `tableName => 'construction_rule_pos'` override
- `suppressConstructionRuleId INTEGER NULLABLE` added to `ParadigmCellOverrides` (D-03)
- `schemaVersion` bumped 15 → 16
- `if (from < 16)` migration block: createTable(constructionRules), createTable(constructionRulePOS), addColumn(suppressConstructionRuleId)
- `beforeOpen` safety nets: `CREATE TABLE IF NOT EXISTS construction_rules`, `CREATE TABLE IF NOT EXISTS construction_rule_pos`, `ALTER TABLE paradigm_cell_overrides ADD COLUMN suppress_construction_rule_id` in try/catch

**construction_rule_dao.dart** (new): `@DriftAccessor(tables: [ConstructionRules, ConstructionRulePOS, PhraseConstructions, ConstructionSlots])` with `watchAll()`, `watchForPos(int posId)`, `insertRule`, `updateRule`, `deleteRule`, `insertPosLink`, `deletePosLinks`, `getPosIdsForRule`, `setPosLinks` (atomic delete+insert transaction)

**construction_rule_providers.dart** (new): hand-written `constructionRuleDaoProvider`, `constructionRuleListProvider`, `constructionRulesForPosProvider` (StreamProvider.family mapping rows to `ConstructionRule.fromDbRow`)
