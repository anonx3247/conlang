   ```dart
   // Construction rule form state (only used when kind == RuleKind.construction)

   ```

   ```dart
   if (widget.existingConstructionRule != null) {
     _editingConstructionRule = widget.existingConstructionRule;
     _selectedConstructionId = widget.existingConstructionRule!.constructionId;
     _selectedWordSlotId = widget.existingConstructionRule!.wordSlotId;
     _formReference = widget.existingConstructionRule!.formReference;

     // Hydrate POS set from DAO in didChangeDependencies or via FutureBuilder
   }
   ```

4. In the `build` method, when `widget.kind == RuleKind.construction`, replace the BranchEditor section with a three-picker construction form. The POS/binding editor section (PosBindingEditor) remains IDENTICAL to inflectional mode — reuse it verbatim.

   The construction-specific form body (replaces BranchEditor):

   a. **Construction picker** — `DropdownButtonFormField<int>`:
      - Label: `"Construction"` (UI-SPEC copywriting contract)
      - Items: watch `constructionListProvider`, map each `PhraseConstruction` to `DropdownMenuItem(value: c.id, child: Text(c.name))`
      - Empty state: disabled dropdown with hint text `"No constructions defined. Add one in Grammar → Constructions."` (UI-SPEC)
      - `onChanged`: set `_selectedConstructionId`, reset `_selectedWordSlotId` to null (new construction = new slots)

   b. **Word slot selector** — `DropdownButtonFormField<int>`:
      - Label: `"Word slot"` (UI-SPEC)
      - Items: watch `constructionSlotsProvider(_selectedConstructionId!)` when `_selectedConstructionId` is non-null, map each slot to `DropdownMenuItem(value: slot.id, child: Text("${slot.slotType}: ${slot.slotValue}"))`
      - Default selection: first slot of type `'pos'` if available (UI-SPEC interaction contract)
      - Disabled when `_selectedConstructionId` is null

   c. **Form reference picker** — Two `RadioListTile<bool>` widgets:
      - Label: `"Resolve word slot as"` (UI-SPEC)
      - Option A (default): `"Base (uninflected) form"` — sets `_formReference = BaseFormReference()`
      - Option B: `"Reference another cell"` — shows a nested `DropdownButtonFormField<String>` listing all `{DimName}: {LevelName}` combinations for the currently selected POS
      - The cell reference picker label: `"Target cell"` (UI-SPEC)
      - The cell reference dropdown items come from dimensions for the selected POS: for each dimension, for each level, emit `DropdownMenuItem(value: featureSetToJson({dimId: levelId}), child: Text("${dim.name}: ${level.name}"))`. When selected, parse back and set `_formReference = CellFormReference(targetFeatureSet: {dimId: levelId})`.
      - For multi-dimensional references (full cell = all dims bound), build the Cartesian product of levels — but this is complex. Simplify: show each single-dimension level as an option. The user picks which dimension:level combination defines the cross-reference. The `CellFormReference.targetFeatureSet` stores the selected `{dimId: levelId}` map. For MVP, this is a single-dimension reference (matches the CONTEXT.md examples: "imperfective", "conditional" are each a single dimension level). If multi-dimension is needed later, extend here.

5. **Save logic** — when `widget.kind == RuleKind.construction`:
   - Validate: `_selectedConstructionId != null`, `_selectedWordSlotId != null`, `_nameCtrl.text.isNotEmpty`
   - If editing (`_editingConstructionRule != null`): call `constructionRuleDao.updateRule(...)` with the updated row, then `constructionRuleDao.setPosLinks(ruleId, _inflectionalPosSet)`
   - If creating: call `constructionRuleDao.insertRule(ConstructionRulesCompanion(...))`, then `constructionRuleDao.setPosLinks(newId, _inflectionalPosSet)`
   - Build the `ConstructionRulesCompanion`:
     ```dart
     ConstructionRulesCompanion(
       name: Value(_nameCtrl.text),
       isActive: const Value(true),
       ordering: const Value(0),
       constructionId: Value(_selectedConstructionId!),
       wordSlotId: Value(_selectedWordSlotId!),
       formReferenceJson: Value(_formReference.toJson()),
       featureBindings: Value(FeatureBindings(pos: _inflectionalPosSet.toList(), dims: _featureBindings)),
     )
     ```
   - After save, call `Navigator.of(context).pop()` to close the dialog (same as existing save flow).

6. **Delete logic** — add a delete IconButton in the dialog header when editing a construction rule:

   ```dart
   IconButton(
     icon: const Icon(Icons.delete_outline),

       final dao = ref.read(constructionRuleDaoProvider);

         await dao.deleteRule(_editingConstructionRule!.id);

     },
   )
   ```
