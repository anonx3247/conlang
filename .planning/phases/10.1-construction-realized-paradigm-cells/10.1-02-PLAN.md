2. Add new function `resolveConstructionCell`:
   ```dart
   /// Resolves a single paradigm cell's construction overlay.
   ///
   /// Called from [generateParadigm] as a post-pass after all inflectional cells
   /// are computed. Returns the original [inflectionalResult] if no construction
   /// rule matches the [target] feature set for this POS.
   ///
   /// D-04: When a construction rule matches AND an inflectional result exists,
   /// the construction wraps the inflected form (composition). The inflectional
   /// chain fires first; the construction's word slot resolves to the inflected
   /// output.
   ///
   /// D-09: Cycle detection via [resolvingStack] — a set of featureSetKeys
   /// currently being resolved. If [target] is already in the set, returns
   /// ParadigmUnresolvable with the cycle path.
   ParadigmCell resolveConstructionCell({
     required String root,
     required FeatureSet target,
     required ParadigmCell inflectionalResult,
     required List<ConstructionRule> constructionRules,
     required List<ConstructionSlot> Function(int constructionId) slotsLookup,
     required List<Lexeme> closedClassWords,
     required Map<String, ParadigmCell> inflectionalChart,
     required Set<String> resolvingStack,
     required Map<String, ParadigmCell> resolvedCache,
     required List<ConstructionRule> allConstructionRules,
     required PhonemeInventory inventory,
     List<PhonologicalRewriteRule> rewriteRules = const [],
   }) { ... }
   ```

   Algorithm:
   a. Find matching construction rules: filter `constructionRules` to those that are active, have non-empty bindings, and whose `bindings.dims` is a subset of `target`. Take highest specificity. If none match, return `inflectionalResult`.
   b. Cycle check: compute `featureSetKey(target)`. If already in `resolvingStack`, return `ParadigmUnresolvable(cyclePath: _buildCyclePath(resolvingStack, target))`.
   c. Add target key to `resolvingStack`.
   d. Resolve the word slot form:
      - If `formReference` is `BaseFormReference`: use the inflectional result. If `inflectionalResult` is `ParadigmFilled`, use its `form`/`phonemic`. If `ParadigmUnmarked`, use its `root`. Otherwise use `root`.
      - If `formReference` is `CellFormReference`: look up `targetFeatureSet` in `resolvedCache` first (already resolved construction cells), then `inflectionalChart` (inflectional-only cells). If the referenced cell is not yet resolved and has its own construction rule, recursively call `resolveConstructionCell` on it. Pass the same `resolvingStack` to enable cycle detection across recursive calls.
   e. Look up slots for the construction via `slotsLookup(winningRule.constructionId)`.
   f. Build `List<ConstructionToken>` by iterating over slots: for each slot, if it is the `wordSlotId`, create a `WordSlotToken(ipa: resolvedForm, phonemic: resolvedPhonemic)`. For `gloss_tag` slots, look up the matching closed-class word by `glossTag` (case-insensitive match, same pattern as `construction_preview.dart`), create `ParticleToken(ipa: match.ipa, romanization: match.romanization)`. For `pos` slots that are NOT the word slot, use the first matching lexeme of that POS as `ParticleToken`.
   g. Apply rewrite pipeline to the FULL assembled form (space-joined IPA). The `phonemic` is the pre-rewrite space-joined string.
   h. Remove target key from `resolvingStack`. Store result in `resolvedCache`.
   i. Return `ParadigmConstructionFilled(tokens: tokens, form: finalForm, phonemic: assembledPhonemic, constructionName: constructionName)`.

   Helper: `_buildCyclePath(Set<String> stack, FeatureSet target)` returns a string like `"Cell FUT → Cell COND → Cell FUT"`. Use dimension/level names if available, else fallback to featureSetKey.
