## What Was Built

### Task 1: Paradigm Table Cell Rendering

**paradigm_table_widget.dart** gained:

**Imports added:**
- `construction_rule_providers.dart` (for `constructionRulesForPosProvider`)
- `construction_rule.dart` (for `ConstructionRule` type)

**`_ConstructionFilledCell` widget** (new `ConsumerWidget`):
- Mirrors `_FilledCell` layout: romanization top line + IPA bottom line with phonotactic violation highlighting
- D-112 invariant preserved: `romanize(phonemic)` for rom line, `[$form]` for IPA display
- Stack with Positioned `Icons.account_tree_outlined` badge (size 10, `cs.primaryContainer` background, `cs.onPrimaryContainer` icon) in top-right corner
- Badge wrapped in `Tooltip(message: 'Analytically realized via $constructionName')`

**`_UnresolvableCell` widget** (new `StatelessWidget`):
- `cs.errorContainer.withValues(alpha: 0.15)` background + `cs.error.withValues(alpha: 0.4)` border
- `Icons.sync_problem` (16px, `cs.error` color) + "Cycle detected" `bodySmall` text
- Wrapped in `Tooltip(message: 'Circular dependency: $cyclePath')`
- `width: double.infinity, height: double.infinity` fills the parent 80×64 container

**Switch extension** — two new exhaustive cases added to the `switch (cell)` expression:
- `ParadigmConstructionFilled(:final form, :final phonemic, :final constructionName)` → `_ConstructionFilledCell`
- `ParadigmUnresolvable(:final cyclePath)` → `_UnresolvableCell` (unreachable but required for exhaustion)

**Inert cell guard** — placed before the `InkWell` return:
```dart
final currentCell = cell;
if (currentCell is ParadigmUnresolvable) {
  return Container(width: 80, height: 64, ...child: _UnresolvableCell(...));
}
```
Uses local variable `currentCell` for Dart type promotion (public field `cell` cannot be promoted).

**Construction click handler** — added `ParadigmConstructionFilled` branch in `openDialog()`:
- Reads `constructionRulesForPosProvider(posId)` synchronously via `ref.read`
- Finds matching rule by name (`r.name == localCell.constructionName`)
- Opens `RuleEditorDialog(kind: RuleKind.construction, existingConstructionRule: matchingRule, ...)`
