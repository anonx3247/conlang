### WR-01: `_saveConstructionRule` redundant double setState on validation failure paths

**Files modified:** `lib/features/morphology/presentation/rules/rule_editor/rule_editor_body.dart`
**Commit:** a652c3e

### WR-02: `ParadigmConstructionFilled._tokenPhonemic` used `ipa` for `ParticleToken`

**Files modified:** `lib/features/grammar/domain/paradigm_cell.dart`
**Commit:** c55a43c
**Applied fix:** Changed the `ParticleToken` arm of `_tokenPhonemic` from `ipa` to `romanization ?? ipa`. This ensures the aggregate `phonemic` field receives the pre-computed romanization string when available (avoiding post-rewrite allophone forms being passed to `romanize()`), with the raw IPA as fallback when no stored romanization exists.

### WR-04: `_buildConstructionForm` conditionally called `ref.watch` — Riverpod hook ordering violation

**Files modified:** `lib/features/morphology/presentation/rules/rule_editor/rule_editor_body.dart`
**Commit:** b3d2a84
**Applied fix:** Replaced the conditional `_selectedConstructionId != null ? ref.watch(...) : null` pattern with an unconditional `ref.watch(constructionSlotsProvider(_selectedConstructionId ?? 0))`. The slots list is then derived conditionally: non-null `_selectedConstructionId` uses the async result, null uses an empty `const <ConstructionSlot>[]`. Provider id `0` returns an empty stream safely (no construction has id=0).
