## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (regular) | 1.5 | Word list entries, meaning text, form field values |
| Label | 12px | 400 (regular) | 1.4 | IPA romanization sub-labels, derivation tree node annotations, Swadesh list concept text |

## Color

All values resolve from `ColorScheme.fromSeed(seedColor: Color(0xFF5B8DEF), brightness: Brightness.dark)` — the exact generated hex values depend on Material 3 tone mapping. Use the named color roles below; do NOT hardcode hex values except for the two semantic overrides specified.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Main background, word detail panel background, lexicon page scaffold |
| Secondary (30%) | `colorScheme.surfaceContainer` | Word list panel background, sidebar navigation background, table view header row, Swadesh/Thesaurus panel background |
| Accent (10%) | `colorScheme.primary` | Selected nav item indicator, active POS filter chip, "Add root" button fill, selected word list item indicator bar, Swadesh coverage progress fill |
| Destructive | `colorScheme.error` | Delete word action, delete exception action, phonotactic violation underline (wavy), stale exception warning icon |
| Exception/Irregular | `Colors.amber` (Material constant) | Derivation tree nodes that are irregular (exception overrides) — amber text on derived word label; established by CONTEXT.md D-05 |

Accent reserved for:
1. Selected sidebar sub-nav item (Dictionary / Swadesh List / Thesaurus) — left indicator bar
2. Active POS filter chip — filled background
3. "Add root" primary action button fill
4. Active selection indicator on word list item
5. Swadesh list coverage progress bar fill
6. "Select all" / export action button

The word creation form, search bar, and table view use `colorScheme.surface` / `colorScheme.surfaceContainer` only — no accent on neutral interactive elements.

Source: `lib/app.dart` (verified); CONTEXT.md D-05 (amber/orange for exceptions); `lib/features/morphology/presentation/rules/morphology_preview_panel.dart` (error color for violations, verified)

## Layout Contract

### Dictionary page (master-detail — D-01)

Primary focal point: the `WordDetailPanel` on the right is the visual anchor of the Dictionary screen. It occupies the dominant surface area, renders at full contrast, and receives focus immediately on word selection. The `WordListPanel` on the left is deliberately lower contrast (`surfaceContainer` background) to direct the eye toward the detail area.

```
┌──────────────────────────────────────────────────────────────┐
│  AppShell top bar (height: 48px)                             │
├──────────────────┬───────────────────────────────────────────┤
│  Lexicon sidebar │  Content area                             │
│  (sub-nav)       │                                           │
│  ─ Dictionary    │  ┌──────────────┐  ┌────────────────────┐│
│  ─ Swadesh List  │  │ WordListPanel│  │ WordDetailPanel    ││
│  ─ Thesaurus     │  │ (scrollable) │  │ (or WordCreation   ││
│                  │  │              │  │  Form + Inspiration ││
│                  │  │              │  │  Panel)             ││
│                  │  └──────────────┘  └────────────────────┘│
└──────────────────┴───────────────────────────────────────────┘
```

- Word list panel: fixed width 280px, `surfaceContainer` background
- Detail panel: fills remaining width, `surface` background
- Panel separator: 1px divider, `colorScheme.outlineVariant`
- Inspiration panel: shown to the right of or below the creation form, width matches half the detail panel — Claude's discretion on exact placement

### Word list panel anatomy

1. Search bar — `TextField` with search icon prefix, `md` (16px) horizontal padding, 40px height
2. POS filter — horizontal `SingleChildScrollView` of `FilterChip` widgets, `sm` (8px) gap between chips, `md` (16px) horizontal padding
3. View toggle — list icon / table icon `IconButton` pair, aligned to right edge of panel header. Each button MUST declare:
   - `tooltip: 'List view'` on the list-icon button (`Icons.list`)
   - `tooltip: 'Table view'` on the table-icon button (`Icons.table_rows`)
   - `semanticsLabel` matching the tooltip text for screen reader support
4. List items (list mode): root word IPA, romanization sub-label (12px, 55% opacity), meaning truncated to 1 line
5. List items (table mode): sortable columns — Word | IPA | POS | Meaning — column headers at 11px caption weight, sortable via header tap

### Word detail panel anatomy

1. IPA + romanization display (heading 13px semibold for primary form, label 12px for secondary)
2. Meaning text (body 13px)
3. POS badge (caption chip)
4. Derivation tree widget — collapsible, `lg` (24px) top margin
5. Exceptions section — list of per-rule overrides; `amber` color for irregular labels
6. Export checkbox — `md` (16px) from bottom of panel
7. Delete action — `colorScheme.error` text button, bottom-right aligned

### Word creation form (inline, D-06)

- Triggered by "+ Add root" button (accent-filled), replaces detail panel content
- Form fields in order: IPA (IpaTextField with keyboard popup), Romanization (auto-populated when romanization enabled, D-07), Meaning (plain TextField), POS (DropdownButtonFormField reusing PartsOfSpeech data)
- Inspiration panel shown to the right — generated word candidates are `TextButton` items; clicking fills the IPA/romanization fields
- "Save" button (accent-filled, label: "Add root") + "Cancel" button (text, no fill)
- Form validation: IPA field must be non-empty; error shown inline below field using `colorScheme.error` text at 11px

## Interaction Contract

### Search & filtering (D-09, D-10, D-11)

- Input latency: 0ms — list filters synchronously on every keystroke (client-side, no debounce needed for <10k entries)
- When a derived form matches: parent root entry appears in list with a `colorScheme.primary`-tinted "n derived matches" badge; detail panel opens with derived form highlighted (bold, `colorScheme.primary`)
- POS filter chips: tapping a chip adds it to the active filter set (multi-select); selected chip uses `colorScheme.primary` filled style; "All" chip deselects all others

### Phonotactic violation highlighting (PHON-05)

- Violation display: wavy underline using `TextDecoration.underline` + `decorationStyle: TextDecorationStyle.wavy` + `decorationColor: colorScheme.error`
- Tooltip on hover: pipe-separated list of violated rule descriptions
- Exception toggle: small "Mark as exception" `TextButton` with `Icons.warning_amber_outlined` prefix appears when violation is detected on a word in the detail panel
- Established pattern reused from `morphology_preview_panel.dart` (verified)

### Derivation tree (D-05)

- Regular derived forms: body text (13px, 400 weight) in `colorScheme.onSurface`
- Exception/irregular forms: label text (12px) in `Colors.amber`
- Tree connector lines: `colorScheme.outlineVariant`, 1px
- Expand/collapse toggle per node level; collapsed by default beyond depth 2

### Swadesh list (D-13)

- Covered concepts: `Icons.check_circle` in `colorScheme.primary`, concept text in `colorScheme.onSurface`, linked word shown as a tappable `colorScheme.primary` text label
- Uncovered concepts: `Icons.radio_button_unchecked` in `colorScheme.onSurface` at 40% opacity, "Add word" action as `TextButton` with accent color (see Copywriting Contract)
- Coverage progress: inline linear progress indicator (height: 8px) above the list, `colorScheme.primary` fill, right-aligned "N/207 — X%" caption text

### Thesaurus (D-14, D-15)

- Tree node with children: `Icons.expand_more` / `Icons.chevron_right` toggle
- Leaf node with no word: `Icons.add_circle_outline` "Name this concept" action in `colorScheme.primary` (see Copywriting Contract)
- Leaf node with word: `Icons.check` in `colorScheme.primary`, word form shown in 12px label
- Search bar filters visible nodes; non-matching nodes are hidden entirely (not greyed out)

### Anki export (D-18)

- Checkboxes: standard Material `Checkbox` widget at default size (18px box)
- "Select all" checkbox in list panel header row
- "Export selected" action button: shown in word list panel footer when 1+ words selected; label "Export to Anki"; accent-filled; shows selected count badge
- Post-export: `SnackBar` confirmation "Exported N words to [filename].apkg" with "Open folder" action
