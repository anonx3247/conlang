    **1. Create AnkiExporter** at `lib/features/lexicon/data/anki_exporter.dart`:

    ```dart
    import 'dart:convert';
    import 'dart:typed_data';
    import 'package:archive/archive.dart';
    import 'package:sqlite3/sqlite3.dart';
    import '../../db/app_database.dart';

    class AnkiExportEntry {
      final String ipa;
      final String? romanization;
      final String? meaning;
      final String? partOfSpeech;
      final String? morphologicalContext; // e.g. "Derived from [root] via [rule]"
      const AnkiExportEntry({
        required this.ipa, this.romanization, this.meaning,
        this.partOfSpeech, this.morphologicalContext,
      });
    }

    class AnkiExporter {
      /// Builds a .apkg file (Uint8List) from the given entries.
      ///
      /// Card layout (per D-17):
      /// - Front: IPA form (+ romanization if present)
      /// - Back: meaning/gloss
      /// - Additional fields: POS tag, morphological context
      ///
      /// No audio field (D-19).
      Uint8List buildApkg({
        required String deckName,
        required List<AnkiExportEntry> entries,
      }) {
        final db = sqlite3.openInMemory();
        try {
          _createSchema(db);
          _insertCol(db, deckName);
          _insertNotes(db, entries);
          _insertCards(db, entries.length);
          final dbBytes = _serializeDb(db);

          final archive = Archive();
          archive.addFile(ArchiveFile('collection.anki21', dbBytes.length, dbBytes));
          archive.addFile(ArchiveFile('media', 2, utf8.encode('{}')));
          return Uint8List.fromList(ZipEncoder().encode(archive)!);
        } finally {
          db.dispose();
        }
      }
    }
    ```

    **Schema creation** — create tables: `col`, `notes`, `cards`, `revlog`, `graves` per Anki schema v11:
    ```sql
    CREATE TABLE col (id INTEGER PRIMARY KEY, crt INTEGER NOT NULL, mod INTEGER NOT NULL, scm INTEGER NOT NULL, ver INTEGER NOT NULL, dty INTEGER NOT NULL, usn INTEGER NOT NULL, ls INTEGER NOT NULL, conf TEXT NOT NULL, models TEXT NOT NULL, decks TEXT NOT NULL, dconf TEXT NOT NULL, tags TEXT NOT NULL);
    CREATE TABLE notes (id INTEGER PRIMARY KEY, guid TEXT NOT NULL, mid INTEGER NOT NULL, mod INTEGER NOT NULL, usn INTEGER NOT NULL, tags TEXT NOT NULL, flds TEXT NOT NULL, sfld TEXT NOT NULL, csum INTEGER NOT NULL, flags INTEGER NOT NULL, data TEXT NOT NULL);
    CREATE TABLE cards (id INTEGER PRIMARY KEY, nid INTEGER NOT NULL, did INTEGER NOT NULL, ord INTEGER NOT NULL, mod INTEGER NOT NULL, usn INTEGER NOT NULL, type INTEGER NOT NULL, queue INTEGER NOT NULL, due INTEGER NOT NULL, ivl INTEGER NOT NULL, factor INTEGER NOT NULL, reps INTEGER NOT NULL, lapses INTEGER NOT NULL, left INTEGER NOT NULL, odue INTEGER NOT NULL, odid INTEGER NOT NULL, flags INTEGER NOT NULL, data TEXT NOT NULL);
    CREATE TABLE revlog (id INTEGER PRIMARY KEY, cid INTEGER NOT NULL, usn INTEGER NOT NULL, ease INTEGER NOT NULL, ivl INTEGER NOT NULL, lastIvl INTEGER NOT NULL, factor INTEGER NOT NULL, time INTEGER NOT NULL, type INTEGER NOT NULL);
    CREATE TABLE graves (usn INTEGER NOT NULL, oid INTEGER NOT NULL, type INTEGER NOT NULL);
    ```

    **col row**: Insert with:
    - `id = 1`, `crt` = epoch seconds, `mod` = epoch millis, `scm` = epoch millis, `ver = 11`, `dty = 0`, `usn = -1`, `ls = 0`
    - `models` = JSON with one model (note type): 4 fields (Front [IPA+romanization], Back [meaning], POS, Context), 1 template (front/back)
    - `decks` = JSON with one deck named `deckName`
    - `conf`, `dconf`, `tags` = minimal valid JSON (`'{}'`, `'{}'`, `'{}'`)
    - Model template HTML: front = `{{Front}}`, back = `{{FrontSide}}<hr id=answer>{{Back}}<br><small>{{POS}} {{Context}}</small>`

    **notes**: One per entry. Fields separated by `\x1f` (U+001F):
    - Field order: Front (IPA + romanization), Back (meaning), POS, Context
    - `guid` = unique string (use entry index or hash)
    - `mid` = model ID (match models JSON)
    - `sfld` = sort field (IPA)
    - `csum` = checksum of sfld (use simple djb2 or crc32)

    **cards**: One per note. `nid` = note id, `did` = deck id, `ord = 0`, all other fields = 0 (new card defaults).

    **_serializeDb**: Use `db.serialize()` to get raw bytes. If `serialize()` is not available in sqlite3 2.9.4, use a temp file approach:
    - Create a temp file path
    - `VACUUM INTO '{tempPath}'`
    - Read the file bytes
    - Delete the temp file
