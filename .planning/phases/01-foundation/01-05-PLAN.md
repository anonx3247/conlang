Create `lib/features/phonology/data/phoneme_dao.dart`:
- Drift `@DriftAccessor` class `PhonemeDao` accessing the `phonemes` table
- Methods:
  - `watchAllPhonemes()` — returns `Stream<List<Phoneme>>` (reactive)
  - `watchConsonants()` — filtered stream where type = 'consonant'
  - `watchVowels()` — filtered stream where type = 'vowel'
  - `insertPhoneme(PhonemesCompanion)` — create
  - `updatePhoneme(Phoneme)` — update
  - `deletePhoneme(int id)` — delete
  - `getPhonemesByIds(List<int> ids)` — for natural class resolution

Create `lib/features/phonology/data/natural_class_dao.dart`:
- Drift `@DriftAccessor` class `NaturalClassDao` accessing `natural_classes` table
- Methods:
  - `watchAllClasses()` — reactive stream
  - `insertClass(NaturalClassesCompanion)` — create
  - `updateClass(NaturalClass)` — update
  - `deleteClass(int id)` — delete
  - `resolveClass(String name)` — looks up class by name, returns list of phoneme IDs (JSON-decoded phonemeIds field)

Register both DAOs in the AppDatabase `@DriftDatabase(daos: [PhonemeDao, NaturalClassDao])` annotation.

Create `lib/features/phonology/data/phoneme_providers.dart`:
- `@riverpod phonemeDao` — derived from currentDatabase, returns PhonemeDao
- `@riverpod consonantList` — watches phonemeDao.watchConsonants(), returns AsyncValue<List<Phoneme>>
- `@riverpod vowelList` — watches phonemeDao.watchVowels()
- `@riverpod allPhonemes` — watches all phonemes
- `@riverpod naturalClassDao` — derived from currentDatabase
- `@riverpod naturalClassList` — watches all natural classes

Run `dart run build_runner build --delete-conflicting-outputs` after creating DAOs.
