  <name>Task 1: IPA data model and audio asset bundling</name>
  <files>lib/features/phonology/data/ipa_data.dart, assets/ipa_audio/, pubspec.yaml, assets/AUDIO_CREDITS.md</files>
  <action>
Create `lib/features/phonology/data/ipa_data.dart`:
- `IpaSound` class with fields: symbol (String), name (String, e.g. "voiced bilabial plosive"), type (consonant/vowel), manner/place/voicing for consonants, height/backness/rounded for vowels, audioAssetPath (String nullable — null means no recording available)
- Static data maps for the full IPA pulmonic consonant chart: organized by manner (plosive, nasal, trill, tap, fricative, lateral fricative, approximant, lateral approximant) x place (bilabial, labiodental, dental, alveolar, postalveolar, retroflex, palatal, velar, uvular, pharyngeal, glottal)
- Static data maps for the IPA vowel chart: organized by height (close, near-close, close-mid, mid, open-mid, near-open, open) x backness (front, near-front, central, near-back, back), with rounded/unrounded pairs
- Include non-pulmonic consonants (clicks, implosives, ejectives) as a separate section
- Include common suprasegmentals and tone diacritics
- Each entry maps to an audio asset path like `assets/ipa_audio/voiced_bilabial_plosive.ogg`

For audio assets:
- Create `assets/ipa_audio/` directory
- Download OGG recordings from Wikimedia Commons for at least the core pulmonic consonants and vowels. Use the standard Wikipedia IPA article audio file naming convention. Target: all pulmonic consonants (~60 unique sounds) and all cardinal vowels (~28 sounds).
- For sounds without available recordings, set audioAssetPath to null (the UI will show a "no audio" indicator)
- The download can be done via curl/wget from Wikimedia Commons URLs like: `https://upload.wikimedia.org/wikipedia/commons/...`
- Name files descriptively: `voiced_bilabial_plosive.ogg`, `voiceless_alveolar_fricative.ogg`, etc.

Create `lib/features/phonology/presentation/shared/ipa_chart/ipa_audio_player.dart`:
- Riverpod provider wrapping a `just_audio` `AudioPlayer` instance
- Method `playSound(String assetPath)` that calls `player.setAsset(assetPath)` then `player.play()`
- Handle null asset paths gracefully (no-op or show brief toast "No audio available")
- Single AudioPlayer instance reused across plays (stop previous before starting new)
- `ref.onDispose` to dispose the AudioPlayer

Create `lib/features/phonology/presentation/shared/ipa_chart/ipa_chart_panel.dart`:
- `IpaChartPanel` widget, fixed width ~280px, scrollable vertically
- Renders the standard IPA pulmonic consonant chart as a grid/table:
  - Columns: places of articulation (bilabial through glottal)
  - Rows: manners of articulation (plosive through lateral approximant)
  - Each cell contains 0-2 symbols (voiceless left, voiced right) per IPA convention
- Below consonants, renders the vowel trapezoid/chart:
  - Standard IPA vowel layout by height x backness
  - Pairs shown as unrounded/rounded
- Each IPA symbol is a clickable button/chip:
  - On click: plays the audio recording via IpaAudioPlayer
  - On hover: shows tooltip with full name (e.g. "voiced bilabial plosive")
  - If no audio available: show a muted/disabled style with "no audio" tooltip
- Include a compact header "IPA Reference" at the top
- Use small, dense typography appropriate for a reference panel (not a primary editing surface)
