Create `lib/features/phonology/data/romanization_dao.dart`:
- Drift `@DriftAccessor` class `RomanizationDao` accessing `romanization_mappings` table
- Methods:
  - `watchAllMappings()` — returns `Stream<List<RomanizationMapping>>` (reactive)
  - `insertMapping(RomanizationMappingsCompanion)` — create
  - `updateMapping(RomanizationMapping)` — update
  - `deleteMapping(int id)` — delete
  - `getAllMappings()` — one-shot fetch for conversion function

Register DAO in AppDatabase `@DriftDatabase(daos: [..., RomanizationDao])`.

Create `lib/features/phonology/data/romanization_providers.dart`:
- `@riverpod romanizationDao` — derived from currentDatabase
- `@riverpod romanizationMappings` — watches all mappings as AsyncValue
- `@riverpod romanize` — a provider that returns a `String Function(String ipa)`:
  - Loads all mappings
  - Sorts by IPA symbol length descending (longest match first, so multi-character IPA like "t͡s" matches before "t")
  - Replaces each IPA symbol in the input string with its Latin mapping
  - Unmapped symbols pass through unchanged
  - This function is used throughout the app wherever IPA needs display in Latin script

Run `dart run build_runner build --delete-conflicting-outputs`.
