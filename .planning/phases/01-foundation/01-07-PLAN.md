Create `lib/features/phonology/domain/phonotactic_dsl.dart`:
- Build a petitparser grammar for syllable structure templates
- Grammar elements:
  - Natural class reference: `[className]` e.g. `[stop]`, `[nasal]`, `[liquid]`, `[tone:H]` — matches square brackets with any alphanumeric+colon content
  - Single-letter class: `C` (all consonants), `V` (all vowels), `N` (nasals if defined), or any uppercase letter mapped to a natural class
  - Literal phoneme: a specific IPA character in the template (for fixed positions)
  - Optional slot: `(segment)` — parentheses mark a slot as optional
  - Required slot: bare segment without parentheses
- Parse result: `List<Slot>` where each `Slot` has:
  - `classReference` (String — class name or single letter)
  - `isOptional` (bool)
  - `literalPhoneme` (String? — if a specific phoneme rather than a class)
- Per research Pitfall 3: place longer/more-specific alternatives before shorter ones in the PEG grammar (className before singleClass before literal)
- Include validation: report parse errors with position and expected token
- Per user CRITICAL constraint: DSL must handle ALL language types — clicks, tones, complex clusters. The grammar itself is type-agnostic; it references user-defined classes which can contain any phonemes. Ensure the grammar accepts multi-character IPA symbols in literal positions and class names with colons (e.g. `[tone:H]`).

Create `lib/features/phonology/domain/word_generator.dart`:
- `WordGenerator` class (or function) that takes:
  - A list of parsed templates (each is `List<Slot>`)
  - A phoneme inventory (consonants, vowels, natural class definitions)
  - A count (how many words to generate)
  - Optional: syllable count range (min/max syllables per word)
- Generation algorithm:
  1. Pick a random template from active templates
  2. For each slot in the template:
     - If optional: randomly include or skip (configurable probability, e.g. 50%)
     - Resolve the class reference to its phoneme list (e.g. "C" -> all consonants, "[stop]" -> phonemes in the stop class)
     - Pick a random phoneme from the resolved list
  3. Concatenate to form a syllable
  4. Repeat for N syllables to form a word
  5. Generate `count` words
- Return `List<String>` of generated IPA words
- Include a `validateWord(String word, List<ParsedTemplate> templates)` function that checks if a given word conforms to the active templates. Returns `ValidationResult` with: isValid, violatingSegments (list of {position, length, reason}).
