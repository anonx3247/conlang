Create `lib/features/project/domain/project.dart`:
- `Project` class with fields: `id` (UUID string), `name`, `createdAt`, `lastOpenedAt`, `directoryPath`
- Include JSON serialization (toJson/fromJson) for registry storage

Create `lib/features/project/data/project_registry.dart`:
- `ProjectRegistry` class that manages a `registry.json` file in `getApplicationDocumentsDirectory()/conlang/`
- Methods: `listProjects()`, `createProject(name)`, `deleteProject(id)`, `updateLastOpened(id)`
- On `createProject`: generate UUID, create directory `{docsDir}/conlang/{id}/`, write initial registry entry
- On `deleteProject`: remove directory recursively, remove from registry JSON
- Use `dart:convert` for JSON read/write, `dart:io` for file operations
- Use `uuid` package (add to pubspec if needed) or `DateTime.now().millisecondsSinceEpoch.toRadixString(36)` for ID generation — Claude's discretion

Create `lib/db/app_database.dart`:
- Drift `@DriftDatabase` class `AppDatabase` with all Phase 1 tables:
  - `phonemes`: id (autoIncrement), symbol (text, IPA), type (text: consonant/vowel), manner (text nullable), place (text nullable), voicing (text nullable), height (text nullable), backness (text nullable), rounded (bool nullable), customProperties (text nullable, JSON)
  - `natural_classes`: id, name (text, e.g. "stop", "nasal"), phonemeIds (text, JSON array of phoneme IDs)
  - `phonotactic_templates`: id, pattern (text, DSL string like "(C)(C)V(C)"), description (text nullable), isActive (bool default true)
  - `phonotactic_constraints`: id, pattern (text, DSL string like "VN -> nasalised V"), description (text nullable), isActive (bool default true)
  - `romanization_mappings`: id, ipaSymbol (text), latinMapping (text)
  - `lexemes`: id, ipa (text), rootId (text nullable, FK to self or roots), ruleIds (text nullable, JSON array), computedForm (text nullable, cache), romanization (text nullable), meaning (text nullable), partOfSpeech (text nullable)
- `schemaVersion = 1`
- `MigrationStrategy` with `onCreate: m.createAll()`, `beforeOpen: PRAGMA foreign_keys = ON`
- Constructor accepts `QueryExecutor` (for LazyDatabase injection)

Create `lib/features/project/data/project_providers.dart`:
- `@riverpod appDocsDirProvider` — async provider that returns documents directory path (cached)
- `@riverpod currentProjectIdProvider` — StateProvider<String?> for the active project ID
- `@riverpod projectDatabase(Ref ref, String projectId)` — family provider that:
  - Gets docsDir from appDocsDirProvider
  - Creates `AppDatabase(LazyDatabase(() async { ... }))` with path `{docsDir}/conlang/{projectId}/project.db`
  - Registers `ref.onDispose(db.close)` — CRITICAL per research Pitfall 1
  - Returns the AppDatabase
- `@riverpod currentDatabase` — derived provider that watches currentProjectId and returns projectDatabase(id) or null
- `@riverpod projectRegistry` — provider for ProjectRegistry instance

Run `dart run build_runner build --delete-conflicting-outputs` to generate Drift and Riverpod code.
