## Decisions Made

- Used `riverpod_generator 3.0.3` (not 4.x): riverpod_generator 4.x has a transitive conflict through `riverpod 3.2.1 → test ^1.0.0 → test_api` that is incompatible with `flutter_test`'s pinned `test_api 0.7.7` when combined with `build_runner 2.4.15`. Version 3.0.3 resolves cleanly.
- Used `drift 2.31.0 + drift_flutter 0.2.8` (not 2.32.x): drift_dev 2.32.x requires `analyzer >=10.0.0` which conflicts with riverpod_generator 3.x's `analyzer >=7.0.0 <9.0.0`. Version 2.31.x uses `analyzer >=8.1.0 <10.0.0` which overlaps at 9.x.
- Dark theme as default for professional desktop tool feel.
