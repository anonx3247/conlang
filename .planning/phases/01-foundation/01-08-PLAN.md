**IPA keyboard fix (ipa_text_field.dart):**

The root cause is that TapRegion wrapping the overlay popup (line 314) has no groupId. Clicks inside the popup are treated as "outside" the TextField's implicit TapRegion, causing focus loss which triggers _onFocusChanged -> _hidePopup before the button's onTap fires.

Fix: Create a shared groupId object and apply it to both the TapRegion around the overlay AND the TextField:

1. Add a field to _IpaTextFieldState: `final _tapGroupId = UniqueKey();` (or `Object()`)
2. On the TapRegion in _buildOverlay (currently at line 314), add `groupId: _tapGroupId`
3. Wrap the TextField (line 255) in a TapRegion with the same `groupId: _tapGroupId` so they are in the same tap group
4. Remove the `onTapOutside` callback from the overlay TapRegion -- the grouping handles this. Instead, keep the existing _hidePopup logic in _onFocusChanged which already handles dismissal when focus truly leaves.

Also fix: The IpaTextField.build() (line 229-239) unconditionally overwrites the caller's suffixIcon with the keyboard toggle icon. This hides the template editor's validation checkmark/X icon. Fix by preserving the caller's suffixIcon:
- If `widget.decoration?.suffixIcon != null` AND `widget.showIpaKeyboard`, use a Row containing both the caller's suffixIcon and the keyboard toggle icon
- If only the caller provides suffixIcon (showIpaKeyboard=false), pass it through unchanged
- If only keyboard is needed, use the keyboard icon alone as today

**Template editor fix (template_editor.dart):**

Line 286: Replace `IpaTextField` with plain `TextField` for the DSL pattern field. The DSL pattern uses C, V, [], () syntax -- not IPA symbols. This single change fixes all three template symptoms: (1) hidden validation icon, (2) unwanted IPA keyboard, (3) stale error illusion from popup obscuring error text.

Change line 286 from `IpaTextField(` to `TextField(` and remove the import of ipa_text_field.dart if no longer used in this file.

**IPA chart overflow fix (ipa_chart_panel.dart):**

The pulmonic consonant grid has cells containing a Row of two _IpaSymbolButton widgets. Each has `minWidth: 12` (line 482), so a pair needs 24px. But columns only get ~20px each (280px panel - padding - row label = ~220px / 11 columns). The 4px shortfall matches the reported overflow.

Fix: In the _IpaSymbolButton widget's Container constraints (around line 482), reduce `minWidth` from `12` to `9`. Also reduce horizontal padding from `1` to `0` if present. This gives each button 9px minimum, pair = 18px, fitting within 20px columns.

If the symbol text overflows at 9px, set the Text fontSize to 10 instead of 11.
