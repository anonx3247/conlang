  <action>
Create `lib/features/phonology/presentation/shared/ipa_keyboard/ipa_keyboard_popup.dart`:
- `IpaKeyboardPopup` widget displaying a grid of IPA symbols organized by category
- Categories (tabs or sections within the popup):
  - Consonants: pulmonic consonants grouped by manner
  - Vowels: organized by height/backness
  - Diacritics: common modifiers (nasalization, aspiration, length, etc.)
  - Suprasegmentals: stress, tone markers (˥ ˦ ˧ ˨ ˩), length marks
  - Other: clicks, implosives, ejectives
- Each symbol is a small tappable button
- On tap: calls a callback `onSymbolSelected(String symbol)` — does NOT handle insertion directly
- Compact layout appropriate for a popup (not full-screen) — roughly 300-400px wide, 200-300px tall
- Tab bar or segmented control at top to switch categories
- Per user decision: should feel like typing linguistic notation, not programming

Create `lib/features/phonology/presentation/shared/ipa_keyboard/ipa_text_field.dart`:
- `IpaTextField` widget that wraps a standard Flutter `TextField`
- Accepts all standard TextField parameters (controller, decoration, onChanged, etc.)
- Uses `CompositedTransformTarget` on the text field and `CompositedTransformFollower` on the overlay
- Uses `OverlayPortal` to show the `IpaKeyboardPopup` anchored below (or above if near screen bottom) the text field
- Popup appears when the field gains focus (or via a small IPA icon button in the field decoration — Claude's discretion on trigger)
- Popup dismisses on: focus loss, Escape key, explicit close button
- On symbol selected from popup: insert the symbol at the current cursor position using `TextEditingController.value` manipulation (preserve existing text, insert at selection)
- Regular keyboard input works normally alongside — the popup is supplementary, not exclusive
- The text field remains focused after inserting a symbol (so user can continue typing)

This widget will be used by Plan 01-05 (inventory editor) and Plan 01-07 (rule editor) wherever IPA input is needed. It must be a drop-in replacement for TextField.

NOTE: This plan may read `lib/features/phonology/data/ipa_data.dart` (created in Plan 01-03) for symbol lists. If 01-03 runs in parallel, define a minimal local symbol list as fallback and integrate with ipa_data.dart once available. Alternatively, the keyboard can define its own symbol constants since the keyboard layout may differ from the chart layout.
