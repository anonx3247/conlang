**Part A — Romanization -> Phoneme sync (romanization_section.dart):**

1. In `_saveEdit()`, after saving the romanization mapping, check if a phoneme with that IPA symbol already exists. Use `ref.read(allPhonemesProvider).value` to get the current list and check `any((p) => p.symbol == ipa)`.

2. If no matching phoneme exists, auto-create one:
   - Determine the type (consonant/vowel) by looking up the symbol in `IpaSound` data (import ipa_data.dart).
   - Use the IpaSound match to pre-fill manner/place/voicing (consonant) or height/backness/rounded (vowel).
   - If the symbol is not found in IpaSound data, create a phoneme with type='consonant' and null features (user can edit later).
   - Call `phonemeDao.insertPhoneme(companion)`.
   - Show a `SnackBar`: "Phoneme /ʃ/ added to inventory" so the user knows.

3. Import `phoneme_dao.dart` and `phoneme_providers.dart` as needed.

**Part B — Phoneme -> Romanization prompt (phoneme_edit_dialog.dart):**

1. In the `_save()` method, after successfully saving a NEW phoneme (not edit), check if romanization is enabled via `ref.read(romanizationEnabledProvider)`.

2. If enabled and no romanization mapping exists for this symbol, show a simple dialog asking: "Add a romanization for /${symbol}/?" with a text field for the Latin representation and "Skip" / "Add" buttons.

3. If the user enters a Latin mapping and taps "Add", insert it via `romanizationDao.insertMapping(...)`.

4. This prompt should only appear for NEW phonemes (not edits) to avoid being annoying. Check `!_isEditing` before showing.

5. Import `romanization_dao.dart` and `romanization_providers.dart`.
