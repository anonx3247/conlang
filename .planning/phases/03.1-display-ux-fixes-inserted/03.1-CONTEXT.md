# Phase 3.1: Display & UX Fixes - Context

**Gathered:** 2026-04-09
**Status:** Ready for planning

<domain>
## Phase Boundary

Fix visual and UX issues from phases 1–3: IPA vowel chart shapes (trapezoid), word display format (romanization-first), Anki card layout, Anki export UX (selection mode), and phoneme inventory romanization toggle. No new features — these are corrections to existing UI.

<decisions>
## Implementation Decisions

### IPA chart shapes (FIX-01)
- **D-01:** Vowel chart rendered as a full trapezoid using CustomPaint, matching the official IPA vowel chart shape. Vowels positioned at their correct acoustic locations within the trapezoid outline.
- **D-02:** Trapezoid applies to BOTH the IPA reference side panel (280px) AND the phoneme inventory vowel grid. Consistent shape everywhere.

### Word display format (FIX-02)
- **D-03:** Word generator shows: `romanization [IPA]` — romanization plain (NO slashes — slashes are reserved for phonemic notation), IPA in square brackets. When no romanization mapping exists, show plain IPA only.
- **D-04:** This is a correction to the standard linguistic notation convention: slashes `/` denote phonemic transcription, brackets `[]` denote phonetic transcription, and romanization has no delimiters.

### Anki card layout (FIX-03)
- **D-05:** Anki card front field: romanization (plain, no delimiters) on first line, `[IPA]` in brackets on second line. Use HTML `<br>` for the line break in the Anki template. When no romanization exists, show plain IPA only.

### Anki export UX (FIX-04)
- **D-06:** Default mode: no checkboxes visible in the word list. An "Export to Anki" button in the toolbar enters selection mode.
- **D-07:** Selection mode: checkboxes appear next to each word, select-all checkbox available. Bottom bar shows "Export N to Anki" (confirm) and "Cancel" (exits selection mode, clears selection).

### Romanization toggle (FIX-05)
- **D-08:** Default display in phoneme inventory: romanization (plain text, e.g. `th`, `sh`, `k`). This is flipped from the original FIX-05 spec — romanization is the default because it's the user's working representation.
- **D-09:** Holding Alt (Option on Mac) reveals phonemic IPA in slashes (e.g. `/θ/`, `/ʃ/`, `/k/`). Uses slashes because these are phonemes, not surface sounds.
- **D-10:** Toggle applies to both phoneme inventory chips AND consonant/vowel grid cells. Consistent behavior across all phoneme displays on the inventory page.

### Claude's Discretion
- CustomPaint implementation details for the trapezoid (line thickness, colors, label placement)
- How to detect Alt key hold in Flutter (HardwareKeyboard listener vs Focus/RawKeyboardListener)
- Exact animation/transition when entering/exiting Anki selection mode
- Layout adjustments needed to fit trapezoid in the 280px side panel

</decisions>

<specifics>
## Specific Ideas

- Romanization is the user's working representation — it should be the default everywhere, with IPA accessible via modifier key or secondary display
- Standard linguistic notation: no delimiters for romanization, `/slashes/` for phonemic, `[brackets]` for phonetic
- Full 3-tier display (romanization /phonemic/ [phonetic]) deferred — current phase uses 2-tier (romanization + [IPA])
- The IPA reference chart panel is a recognizable tool for linguists — the trapezoid shape matters for credibility and usability

</specifics>

<deferred>
## Deferred Ideas

- **Full 3-tier phonological display** (romanization /phonemic/ [phonetic]) — requires allophone processing maturity and phonological rule application to surface forms. Consider for Phase 3.2 or later.

</deferred>
