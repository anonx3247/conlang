# Phase 3.1 Plan 03: Anki Export Selection Mode UX Summary

Replaced always-visible checkbox approach with a selection mode pattern: "Export to Anki" toolbar button enters selection mode, per-row checkboxes appear, a bottom bar provides confirm/cancel actions. Clean default word list view with intentional export workflow (D-06, D-07).

## Tasks Completed

| Task | Description | Commit |
|------|-------------|--------|
| 1 | Add selection mode state to DictionaryPage and pass to WordListPanel | 94b51fb |
| 2 | Refactor WordListPanel for selection mode — conditional checkboxes, toolbar button, bottom bar | 94b51fb |

## What Was Built

**DictionaryPage (`dictionary_page.dart`):**
- `bool _isSelectionMode = false` field
- `_enterSelectionMode()` — sets `_isSelectionMode = true`, clears `_selectedForExport`
- `_exitSelectionMode()` — sets `_isSelectionMode = false`, clears `_selectedForExport`
- `_exitSelectionMode()` called after successful export
- New props `isSelectionMode:`, `onEnterSelectionMode:`, `onExitSelectionMode:` passed to `WordListPanel`

**WordListPanel (`word_list_panel.dart`):**
- New constructor params: `bool isSelectionMode`, `VoidCallback? onEnterSelectionMode`, `VoidCallback? onExitSelectionMode`
- Toolbar: `AnimatedSwitcher(150ms)` switches between "Export to Anki" `OutlinedButton.icon` (default) and select-all `Checkbox` (selection mode)
- "Export to Anki" button disabled when `filteredLexemes.isEmpty`
- Per-row checkboxes wrapped in `if (widget.isSelectionMode)` guard — hidden by default
- Bottom bar: `AnimatedSwitcher(150ms)` on a `SizedBox.shrink` / selection bar swap
- Bottom bar contains: `FilledButton.icon` "Export N to Anki" (disabled when count==0) + `TextButton` "Cancel selection"
- Removed old always-visible `_buildExportFooter` (shown on `selectedForExport.isNotEmpty`) — replaced by selection mode bottom bar
