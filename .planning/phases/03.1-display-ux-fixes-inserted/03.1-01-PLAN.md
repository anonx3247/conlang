Replace the `_VowelChart` widget (currently a Row/Column grid, lines ~267-383) with a CustomPaint-based trapezoid implementation. Per D-01 and D-02:

1. Create a `VowelTrapezoidPainter extends CustomPainter` class (can be file-private `_VowelTrapezoidPainter`):
   - Constructor takes: `Map<VowelHeight, Map<VowelBackness, List<IpaSound>>> vowelData`, `Color outlineColor`, `Color tickColor`, `TextStyle symbolStyle`
   - Trapezoid geometry: The standard IPA vowel chart is a trapezoid where:
     - Top-left corner = close-front (0, 0)
     - Top-right corner = close-back (width, 0)
     - Bottom-left corner = open-front (0, height) — left edge is VERTICAL
     - Bottom-right corner = open-back (width * 0.55, height) — right edge is DIAGONAL (back vowels converge toward center at open height)
     - Actually the standard IPA trapezoid: left edge vertical, top edge full width, bottom edge shorter (indented on the right), right edge diagonal connecting top-right to bottom-right
   - Draw outline: `Paint()..style = PaintingStyle.stroke..strokeWidth = 1.0..color = outlineColor` (outlineColor = `colorScheme.outline` at alpha 0.5)
   - Draw horizontal guide lines at each VowelHeight level (7 levels from close to open, evenly spaced vertically) using same paint but alpha 0.15
   - Draw the vertical midline guide at the "central" backness position, alpha 0.15

2. Vowel positioning within the trapezoid:
   - Y axis: VowelHeight maps to vertical position (0.0 = close at top, 1.0 = open at bottom). Map each height to a fraction:
     - close=0.0, nearClose=0.143, closeMid=0.286, mid=0.429, openMid=0.571, nearOpen=0.714, open=0.857 (roughly 1/7 increments, last row at ~6/7 to leave bottom margin)
   - X axis: VowelBackness maps to horizontal position, but the x range narrows at lower heights (trapezoid effect). For each height row:
     - Left boundary (front) = 0 (constant, left edge is vertical)
     - Right boundary (back) = lerp(width, width * 0.55, yFraction) — interpolates from full width at top to 55% width at bottom
     - Then within that range, backness maps: front=0.0, nearFront=0.25, central=0.5, nearBack=0.75, back=1.0
   - For each position with vowels, draw unrounded symbol on the left, rounded symbol on the right. If both exist, draw a thin tick mark (1px vertical line, 8px tall, tickColor = `colorScheme.outline` alpha 0.3) between them with 2px spacing.
   - Symbol text: use `TextPainter` with style 13px monospace, weight 400, color `colorScheme.onSurface`.

3. Replace the `_VowelChart` widget body:
   - Keep the class signature: `_VowelChart({required this.audioPlayer})`
   - Replace the Column/Row grid with a `SizedBox(width: 264, height: 120)` containing a `Stack`:
     - Bottom layer: `CustomPaint(painter: _VowelTrapezoidPainter(...))`
     - Top layer: Positioned `_IpaSymbolButton` widgets at each vowel's computed (x, y) position (so they remain tappable for audio playback)
   - Use `IpaSound.vowelsByHeightAndBackness` to get the data
   - Compute positions in the build method, place `Positioned` widgets in the Stack

4. If a vowel from `IpaSound` data does not have height/backness, skip it with a debugPrint warning (per UI-SPEC fallback).

5. Outline stroke: 1px, `colorScheme.outline` at alpha 0.5 per UI-SPEC.
