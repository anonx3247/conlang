# Phase 3.1 Plan 01: IPA Vowel Chart Trapezoid Summary

**One-liner:** Standard IPA trapezoid vowel chart via CustomPainter in both the IPA reference panel and phoneme inventory, with vowels at acoustic positions and interactive elements preserved.

## What Was Built

Both IPA vowel chart locations now render as the standard IPA trapezoid shape:

**Shared geometry (`vowel_trapezoid_painter.dart`):**
- `VowelTrapezoidPainter extends CustomPainter` — draws trapezoid outline (1px, outline@50% alpha) and horizontal guide lines at each of 7 VowelHeight levels (0.5px, outline@15% alpha)
- `vowelPosition()` helper — computes pixel (x,y) within any size from height/backness enums. Left edge is vertical; right boundary narrows from 100% width (close row) to 55% (open row)
- `vowelHeightToYFraction()` and `vowelBacknessToXFraction()` — enum-to-fraction mapping functions

**IPA reference panel (`ipa_chart_panel.dart` — Task 1):**
- `_VowelChart` replaced: Row/Column grid removed, now `SizedBox(264x120)` with `Stack`
- `CustomPaint(VowelTrapezoidPainter)` as bottom layer; `Positioned` `_IpaSymbolButton` widgets as top layer
- Unrounded/rounded pairs separated by 1px tick mark (`outline@30%` alpha)
- Audio playback preserved on all symbol buttons

**Phoneme inventory (`inventory_page.dart` — Task 2):**
- `_VowelChart` replaced: old Row/Column grid removed, now `LayoutBuilder` + `Stack`
- `_heightFromString()` and `_backnessFromString()` helpers map DB string values to enums
- Vowels at unknown positions emit `debugPrint` and are skipped (no crash)
- `_PhonemeChip` widgets positioned as overlays at trapezoid acoustic coordinates
- Trapezoid scales to available width (min 200px, 2.2:1 aspect ratio, height capped at 200px)
