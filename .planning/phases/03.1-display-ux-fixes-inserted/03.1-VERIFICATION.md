#### 1. IPA Reference Panel Trapezoid Shape

**Test:** Open the app with a project, navigate to the IPA reference side panel (Phonology section), expand the vowel chart
**Expected:** Vowel chart renders as the standard IPA trapezoid — vertical left edge (front vowels), diagonal right edge (back vowels converging toward center at the open row), with horizontal guide lines at each vowel height level. Vowel symbols appear at correct acoustic positions (close-front top-left, open-back bottom-right). Unrounded/rounded pairs are side by side with a tick mark separator.
**Why human:** CustomPainter geometry and visual positioning cannot be verified programmatically

#### 2. Phoneme Inventory Vowel Trapezoid

**Test:** Navigate to Phonology > Phoneme Inventory, view the vowel grid section
**Expected:** Vowel grid renders as a trapezoid matching the IPA reference panel shape. Phoneme chips for user-defined vowels appear at their acoustic positions within the trapezoid. Trapezoid scales to available panel width.
**Why human:** CustomPainter layout and chip positioning require visual inspection

#### 3. Word Generator Display Format

**Test:** Navigate to Phonology > Sound Rules > Word Generator. Generate words in a project that has romanization mappings defined.
**Expected:** Words appear as `romanization [IPA]` — romanization is the primary (larger, full opacity) text, followed by the IPA in square brackets as secondary (smaller, dimmer). No slashes around romanization. When a word has no romanization mapping, only plain IPA is shown.
**Why human:** Text rendering order and visual prominence require running the app with real romanization data

#### 4. Anki Export Selection Mode Flow

**Test:** Navigate to Lexicon > Dictionary. Observe the default word list, then tap "Export to Anki."
**Expected:**
- Default state: No checkboxes visible anywhere in the word list. Only an "Export to Anki" button (with download icon) in the toolbar — disabled if word list is empty.
- After tapping "Export to Anki": Selection mode activates with 150ms animation. Checkboxes appear next to each word. A select-all checkbox appears in the toolbar. A bottom bar slides in showing "Export 0 to Anki" (disabled) + "Cancel selection."
- After selecting words: "Export N to Anki" becomes enabled.
- After tapping "Cancel selection": Returns to default mode, no checkboxes, selection cleared.
**Why human:** Interactive UX state transitions require running the app

#### 5. Phoneme Inventory Alt Key Toggle

**Test:** Navigate to Phonology > Phoneme Inventory in a project with romanization mappings. Observe phoneme chips normally, then hold Alt (Option on Mac).
**Expected:**
- Default: Phoneme chips show romanization text (e.g., "th", "sh", "k") — plain, no delimiters
- While holding Alt: ALL chips switch simultaneously to /IPA/ notation (e.g., "/θ/", "/ʃ/", "/k/")
- On release: All chips return to romanization immediately
- Chips with no romanization mapping show plain IPA symbol (no slashes) in both modes
- IPA reference side panel is NOT affected — always shows raw IPA symbols
**Why human:** Keyboard-driven real-time toggle requires running the app
