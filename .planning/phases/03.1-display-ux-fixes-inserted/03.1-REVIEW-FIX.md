### WR-02: `ref.watch(allLexemeListProvider)` called inside `ListView.builder` itemBuilder

**Files modified:** `lib/features/lexicon/presentation/dictionary/word_list_panel.dart`
**Commit:** a871491
**Applied fix:** Hoisted `ref.watch(allLexemeListProvider).asData?.value ?? []` from inside `itemBuilder` to the top of `_buildListView`, so there is now a single subscription per rebuild instead of one per visible row. The itemBuilder closes over the resolved list for its derived-match counting.

### WR-03: `_shortPlace` crashes on empty string input

**Files modified:** `lib/features/phonology/presentation/inventory/inventory_page.dart`
**Commit:** 483b934
**Applied fix:** Rewrote the fallback branch to first check the lookup map explicitly, then guard `p.substring(0, 2)` with a `p.length < 2` check so empty or single-character place strings from malformed DB rows no longer throw `RangeError` during consonant grid render.

### WR-04: `_revealInFinder` is fire-and-forget — unhandled async

**Files modified:** `lib/features/lexicon/presentation/dictionary/dictionary_page.dart`
**Commit:** 9f449ca
**Applied fix:** Wrapped each `Process.run(...)` call in `unawaited(...)` to explicitly acknowledge fire-and-forget intent and satisfy the `unawaited_futures` lint. Added `import 'dart:async';` to provide the `unawaited` helper.

### WR-05: `noteId` uniqueness degrades when `entries.length > 1000` within the same second

**Files modified:** `lib/features/lexicon/data/anki_exporter.dart`
**Commit:** 0b00839
**Applied fix:** Switched `noteId` in `_insertNotes` from `now(seconds) * 1000 + i` to `nowMs(milliseconds) * 10000 + i`, which safely supports lexicons of up to 10,000 entries per millisecond without PK collisions. Applied the same widening to `cardId` in `_insertCards` (`nowMs * 10000 + 1000000 + i`) to prevent the identical collision in the `cards` table for large exports.
