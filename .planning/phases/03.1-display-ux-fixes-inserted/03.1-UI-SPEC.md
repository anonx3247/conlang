**Notes:**

## Color

Source: `lib/app.dart` — `ColorScheme.fromSeed(seedColor: Color(0xFF5B8DEF), brightness: Brightness.dark)`.
All color references must use `Theme.of(context).colorScheme.*` tokens — no hardcoded hex in widgets.

| Role | ColorScheme token | Usage |
|------|------------------|-------|
| Dominant (60%) | `colorScheme.surface` / `colorScheme.surfaceContainerLow` | App background, IPA chart panel background |
| Secondary (30%) | `colorScheme.surfaceContainer` / `colorScheme.surfaceContainerHigh` | Word list panel, detail panel, cards |
| Accent (10%) | `colorScheme.primary` (approx. #5B8DEF derived) | See accent reserved-for list below |
| Destructive | `colorScheme.error` | Phonotactic violation underlines, warning icons only |

**Accent reserved for:**
- IPA chart section labels (primary at alpha 0.8)
- Selected/active phoneme chips (`primaryContainer` fill)
- "Export to Anki" toolbar button (filled style — the sole primary action)
- "Export N to Anki" confirm button in selection mode bottom bar

**Accent NOT used for:** word row romanization text, grid lines, empty cell borders, selection checkboxes (use onSurface), cancel button (use surfaceVariant/outlined style).

**Alt-key IPA reveal on phoneme chips:** When Alt is held, chip switches from romanization display to IPA display. Visual change is text content only — chip background color (`primaryContainer`) and border remain unchanged. No color state change for the toggle itself.

**Anki selection mode checkboxes:** Use `Checkbox` with Material3 defaults — `colorScheme.primary` fill when checked. Do not override checkbox color.

## Component Contracts

This phase fixes existing widgets rather than creating new ones. Each component's contract is described below.

### FIX-01: IPA Vowel Chart — Trapezoid CustomPaint

**Applies to:** `_VowelChart` in `ipa_chart_panel.dart` AND the vowel grid section in `inventory_page.dart`.

- Replace the current Row/Column grid with a `CustomPainter` that draws the standard IPA trapezoid outline.
- Trapezoid geometry: top-left = close-front, top-right = close-back, bottom-left = open-front, bottom-right = open-back. The left (front) edge is vertical; the right (back) edge is diagonal. This matches the published IPA chart shape.
- Outline: 1px stroke, `colorScheme.outline` at alpha 0.5.
- Vowel symbols positioned at their acoustic coordinates within the trapezoid. Each vowel position holds up to 2 symbols (unrounded left, rounded right) separated by a thin vertical tick mark (1px, `colorScheme.outline` at alpha 0.3).
- Symbol text: 13px monospace, weight 400, color `colorScheme.onSurface`.
- In the IPA reference panel: maximum width 264px (280px panel minus 8px padding each side). Height: match the acoustic aspect ratio of the official IPA chart, approximately 120px tall within the 280px panel.
- In the phoneme inventory vowel grid: same trapezoid shape scaled to fit available width. Occupied symbols shown as tappable chips (`primaryContainer` background, matching `_PhonemeChip` existing style).
- Fallback: if `IpaSound` data does not contain position data for a vowel, log a warning and skip that symbol (no crash).

### FIX-02: Word Generator Display Format

**Applies to:** `_WordRow` in `word_generator_panel.dart`.

Current format: IPA (primary) + `/ romanization /` (secondary, with incorrect slashes).
New format (from D-03 and D-04):
- When romanization mapping exists AND differs from IPA: `romanization` (plain, weight 400, bodyMedium, `onSurface`) then 8px gap then `[IPA]` (brackets, bodySmall 12px, weight 400, `onSurface` at alpha 0.55).
- When no romanization mapping exists OR romanization equals IPA: plain IPA only, bodyMedium.
- Remove the `/ /` slashes from the secondary display. IPA goes in `[ ]` square brackets.
- `ViolationText` widget applies to the IPA string (the phonetically accurate form). Keep existing violation underline behavior on the IPA portion.
- Violation warning icon: retain at right, 14px, `colorScheme.error`.

### FIX-03: Anki Card Front Field Format

**Applies to:** `AnkiExporter._insertNotes` in `anki_exporter.dart`.

Current format: `${ipa} [${romanization}]`
New format (from D-05):
- When romanization exists: `${romanization}<br>[${ipa}]` — romanization plain on line 1, IPA in brackets on line 2, separated by HTML `<br>`.
- When no romanization: `${ipa}` — plain IPA only.
- No delimiter around romanization. Square brackets only around IPA.
- This is a data format change in the Anki .apkg file — no visual widget change in the Flutter UI.

### FIX-04: Anki Export UX — Selection Mode

**Applies to:** `WordListPanel` and `dictionary_page.dart`.

Current state: checkboxes always visible, export button always present.

New interaction contract (from D-06, D-07):

**Default mode (no selection):**
- No checkboxes in word list rows.
- Toolbar contains one "Export to Anki" button (outlined style, Icon: `Icons.file_download_outlined`, label: "Export to Anki"). Minimum touch target 44px height.
- Tapping "Export to Anki" enters selection mode.

**Selection mode:**
- A `Checkbox` appears to the left of each word row. Word row layout adjusts to accommodate it (prefix checkbox, not suffix).
- A "Select all" checkbox appears in the toolbar/list header area, labeled "Select all".
- Bottom bar (persistent, slides in from bottom or appears as a fixed footer at the bottom of the word list panel):
  - Left: "Export N to Anki" button (filled/primary style) — N is the count of selected words. Disabled when N = 0. Label updates live as selection changes.
  - Right: "Cancel selection" button (text/outlined style). Tapping clears selection and exits selection mode.
- No modal dialog for confirm — the "Export N to Anki" button is the confirm action. It triggers export immediately then exits selection mode.
- Entry/exit animation: AnimatedSwitcher or AnimatedContainer, duration 150ms. No elaborate transitions.

**Empty selection state copy (bottom bar when 0 selected):**
- "Export 0 to Anki" button is disabled (visually muted, not hidden).

### FIX-05: Phoneme Inventory Romanization Toggle

**Applies to:** `_PhonemeChip` in `inventory_page.dart` AND `_PhonemeCell` consonant/vowel grid cells.

Current state: shows IPA symbol.
New state (from D-08, D-09, D-10):

**Default display (no modifier key held):**
- Show romanization (plain text, e.g. `th`, `sh`, `k`) from `romanizeProvider`.
- If romanization is empty or equals the IPA symbol (no mapping defined), show the IPA symbol as fallback.

**Alt/Option key held:**
- Show `/IPA/` in slashes (phonemic notation, e.g. `/θ/`, `/ʃ/`, `/k/`).
- Chip background and size remain identical — only the text content changes.

**Implementation contract:**
- Use `HardwareKeyboard.instance.isAltPressed` (check in a `StatefulWidget` with `HardwareKeyboard.instance.addHandler` in `initState` / `removeHandler` in `dispose`).
- The `_PhonemeChip` widget must become a `StatefulWidget` (or be wrapped in a parent stateful widget) to respond to keyboard state.
- Alternatively: use a single `HardwareKeyboard` listener at the page level (`inventory_page.dart`) that holds an `isAltHeld` boolean in `_InventoryPageState`, and pass it down to chips/cells. This avoids one listener per chip — use the page-level approach.
- Tooltip: do not change. Tooltip continues to show the full articulation description regardless of display mode.
- Applies to BOTH chip display in the phoneme inventory list AND cell display in the consonant/vowel grids on the inventory page. Does NOT apply to the IPA reference side panel (the reference chart shows raw IPA always).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (Anki export entry) | "Export to Anki" |
| Selection mode confirm | "Export N to Anki" (N = integer count, updates live) |
| Selection mode cancel | "Cancel selection" |
| Select all label | "Select all" |
| Empty selection state (0 selected) | Button label reads "Export 0 to Anki" — disabled |
| No romanization fallback | Show IPA symbol as-is — no label, no tooltip change |
| Violation warning icon tooltip | (pre-existing — no change) |
| IPA chart section labels | "Pulmonic Consonants", "Vowels", "Non-Pulmonic" (pre-existing — no change) |

**Destructive actions in this phase:** None. Anki export is non-destructive. No confirmation dialogs required.

**Error states:**
- If Anki export fails (file write error): show `SnackBar` with `"Export failed. Check disk space and try again."` (pre-existing SnackBar pattern — reuse it).
- If trapezoid rendering encounters unknown vowel positions: silent skip (no user-visible error).

**Empty states:**
- Word list empty (no words yet): pre-existing empty state in `WordListPanel` — no change.
- Selection mode with no words: "Export to Anki" button is disabled (grayed). Do not enter selection mode when word list is empty.
