1. **Make the inventory page stateful for keyboard tracking.** The top-level inventory page widget (find it — likely `InventoryPage` or similar `ConsumerWidget`) needs to become a `ConsumerStatefulWidget` if it isn't already, to hold the `_isAltHeld` state. If the page is already `ConsumerStatefulWidget`, just add the state field.

   Add to the state class:
   ```dart
   bool _isAltHeld = false;

   bool _handleKeyEvent(KeyEvent event) {
     final altPressed = HardwareKeyboard.instance.isAltPressed;
     if (altPressed != _isAltHeld) {
       setState(() => _isAltHeld = altPressed);
     }
     return false; // Don't consume the event
   }

   @override
   void initState() {
     super.initState();
     HardwareKeyboard.instance.addHandler(_handleKeyEvent);
   }

   @override
   void dispose() {
     HardwareKeyboard.instance.removeHandler(_handleKeyEvent);
     super.dispose();
   }
   ```

   Import `import 'package:flutter/services.dart';` for `HardwareKeyboard` and `KeyEvent`.
