## Decisions Made

- **List<String>.from on seed** — When seeding the merge map from `defaultNaturalClasses.entries`, values are copied via `List<String>.from(entry.value)` rather than aliased. The runtime map is mutable (user entries overwrite keys), but the defaults themselves are const and must stay pristine across calls. This is a pure-defensive copy at near-zero cost (9 small lists).
- **Deferred items log format** — Created `deferred-items.md` at the phase level (not per-plan) so subsequent plans can append their own out-of-scope findings without file proliferation.
- **Test fixture style matches morphology_engine_test.dart** — Used private top-level helpers `_phoneme` and `_natClass` (with `_malformedNatClass` variant) for concise fixture construction, mirroring how `testInventory` is built in `test/morphology_engine_test.dart`.
- **Did NOT touch WordGenerator or morphology_engine in this plan** — The F-1 architectural insight is that patching the DAO method would have been invisible; patching `buildInventory` propagates defaults through the Riverpod `phonemeInventoryProvider` → `generatedWordsProvider` chain AND through any other reader of `phonemeInventoryProvider`. Single integration point, minimum blast radius. Plan 02 will handle alias wiring in `_resolveClass` and `resolvePhonemeClass`.
