## Decisions Made

- **db. alias resolves naming collision:** Both `app_database.dart` (Drift) and `morphology_dsl.dart` (domain) define `MorphologicalRule`. Added `import '../../../../db/app_database.dart' as db;` in rule_editor_dialog.dart, using `db.MorphologicalRule` for the `existing` parameter and `db.MorphologicalRulesCompanion` for insert. Domain `MorphologicalRule` (unaliased) used for DSL operations.
- **Local state for editor:** `RuleEditorDialog` is a `ConsumerStatefulWidget` with local `List<_BranchState>` — ephemeral form state doesn't belong in Riverpod providers. Providers only used for save (DAO) and preview (phoneme inventory, generated words).
- **ref.read() in Timer callback:** `PreviewPanel._evaluate()` uses `ref.read()` inside the `Timer` callback to avoid stale closure issues and unnecessary rebuilds during debounce.
