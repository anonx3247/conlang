Two related UAT issues:

**A) No auto-select on load (UAT item 8):**
In `dictionary_page.dart`, the `_selectedLexemeId` is initialized to `null` (line 43) which is correct. However, the table view (`_buildTableView` in word_list_panel.dart) uses DataRow's `selected` property. At line 624-625:
```dart
final isSelected = widget.isSelectionMode
    ? widget.selectedForExport.contains(lexeme.id)
    : widget.selectedLexemeId == lexeme.id;
```
When NOT in selection mode, `isSelected` highlights the row matching `selectedLexemeId`. Since `_selectedLexemeId` starts null, this should be fine for the table view. But `DataRow(selected: isSelected, onSelectChanged: ...)` — when `onSelectChanged` is non-null, DataTable renders a leading checkbox column automatically. This is the Flutter DataTable behavior: providing `onSelectChanged` implies selection checkboxes.

Fix in `word_list_panel.dart` `_buildTableView`:
- Change `onSelectChanged` to be `null` when NOT in selection mode. Currently at line 640-642:
  ```dart
  onSelectChanged: (_) => widget.isSelectionMode
      ? widget.onToggleExport?.call(lexeme.id)
      : widget.onWordSelected(lexeme.id),
  ```
  Split this: when `widget.isSelectionMode` is false, use `onSelectChanged: null` and instead wrap the DataRow tap via a GestureDetector or use `DataCell`'s `onTap`. Actually, the simplest fix: set `onSelectChanged: null` when NOT in selection mode. For non-selection navigation, add `onTap` to each DataCell or use a different approach.

  Revised approach: Use `onSelectChanged` only in selection mode. For normal mode, use the first DataCell's onTap for navigation:
  ```dart
  onSelectChanged: widget.isSelectionMode
      ? (_) => widget.onToggleExport?.call(lexeme.id)
      : null,
  ```
  Then add navigation via DataCell onTap on ALL cells:
  ```dart
  DataCell(
    Text(...),
    onTap: widget.isSelectionMode ? null : () => widget.onWordSelected(lexeme.id),
  ),
  ```
  Apply `onTap` to every DataCell in the row (Word, IPA, POS, Meaning) so clicking anywhere navigates.

- Also set `showCheckboxColumn: false` on the `DataTable` widget when NOT in selection mode. Add a property: `showCheckboxColumn: widget.isSelectionMode`.

**B) List view checkboxes already correct:**
The list view (`_buildListView`) already correctly guards checkboxes behind `if (widget.isSelectionMode)` at line 435. No change needed there.

**C) Verify no auto-selection on load:**
In `dictionary_page.dart`, confirm `_selectedLexemeId` starts null and nothing in `initState` or provider watchers auto-selects a word. The current code at lines 53-58 only sets `_isCreating` if `createWithMeaning` is passed. This is correct. No change needed in dictionary_page.dart for auto-select.
