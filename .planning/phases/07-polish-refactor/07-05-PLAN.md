UAT item 7: ResizableDivider shows resize cursor but panels don't actually resize. Two root causes:

**A) IPA chart panel in PhonologyShell (phonology_shell.dart):**
The shell stores `_ipaChartWidth` and updates it on drag (line 113), but the IPA chart panel is rendered as `const IpaChartPanel()` without a SizedBox wrapper (line 118). The `IpaChartPanel` itself has a hardcoded `SizedBox(width: 280)` inside.

Fix in `phonology_shell.dart`:
- Wrap `IpaChartPanel()` in `SizedBox(width: _ipaChartWidth, child: const IpaChartPanel())` at line 118. Remove `const` from IpaChartPanel since it's now wrapped.

Fix in `ipa_chart_panel.dart`:
- Remove the outer `SizedBox(width: 280, ...)` wrapper at line 23-24. Replace with just the `Material(...)` child directly, so the panel takes the width given by its parent. The parent SizedBox in phonology_shell will control width.

**B) Dictionary page word list panel (dictionary_page.dart):**
The word list panel uses a hardcoded `SizedBox(width: 280, ...)` at line 313 and a non-draggable `VerticalDivider` at line 329. The detail panel is `Expanded`.

Convert `DictionaryPage` from `ConsumerStatefulWidget` (it already is one) and add a `_wordListWidth` state variable:
1. Add `double _wordListWidth = 280;` to `_DictionaryPageState`.
2. Replace `SizedBox(width: 280, ...)` at line 313 with `SizedBox(width: _wordListWidth, ...)`.
3. Replace the `VerticalDivider(...)` at lines 329-333 with:
   ```dart
   ResizableDivider(
     onDrag: (d) => setState(() {
       _wordListWidth = (_wordListWidth + d).clamp(200, 400);
     }),
   ),
   ```
4. Add import for `resizable_divider.dart`.
5. Min 200px (enough for word + POS inline), max 400px (leaves room for detail panel).

**C) Verify existing shell resizing works:**
The Grammar, Lexicon, and Phonology shells already have correct ResizableDivider + SizedBox(width: _sidebarWidth) patterns with clamp(140, 320). These should work. The AppShell glossary drawer also has the correct pattern. No changes needed to these.
