# Phase 5 — UI Design Contract: Culture Wiki

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Flutter Material 3) |
| Preset | not applicable |
| Component library | Flutter Material 3 widgets — `Material`, `InkWell`, `TextField`, `ListTile`, `Tooltip`, `Dialog` |
| Icon library | Flutter `Icons.*` (Material Icons) |
| Font | monospace (inherits project-wide `fontFamily: 'monospace'` from `app.dart`) |

**Note:** This is a Flutter/Dart desktop app. shadcn is not applicable. The design system is the existing Material 3 dark theme defined in `lib/app.dart`. No new system initialization is needed.

Source: `lib/app.dart` — `_buildDarkTheme()` / `ThemeMode.dark`

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip internal padding |
| sm | 8px | Sidebar tile vertical padding, inline element spacing |
| md | 16px | Panel horizontal padding, dialog content padding |
| lg | 24px | Section padding, empty state icon-to-text gap |
| xl | 32px | Empty state heading-to-body gap |
| 2xl | 48px | Empty state icon size baseline reference |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Tree sidebar width: 240px (wider than Grammar/Lexicon 200px to accommodate tree indentation + emoji icon + page title)
- Sidebar tree item height: 32px (compact tree nodes, vs. 40px for top-level sidebar items)
- Top-level sidebar section header height: 40px (matches existing shell pattern from `grammar_shell.dart`)
- Tree indent per level: 16px per depth level (starting at depth 1 = 16px, depth 2 = 32px)
- Drag handle affordance zone: 32px touch width
- Back/forward nav bar height: 36px
- Link hover preview tooltip max width: 320px, max height: 180px
- Broken-link `?` badge: 16px diameter

Source: Derived from `app_shell.dart` (48px top bar, 40px tab height) and `grammar_shell.dart` (200px sidebar, 40px tiles, 16px padding) patterns.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (normal) | 1.5 | Rendered Markdown paragraph text, list items, page content |
| Label | 12px | 400 (normal) | 1.4 | Tree sidebar page titles, timestamps, metadata text, CULTURE section header label, broken-link badge text |
| Heading | 16px | 600 (semibold) | 1.3 | Markdown `##` rendered headings, page title in header |
| Display | 20px | 600 (semibold) | 1.2 | Page title (`#` H1), section page header |

Typography weights used: **400 (normal) and 600 (semibold)** — exactly 2 weights.
Typography sizes used: **12, 13, 16, 20** — exactly 4 sizes.

Additional text rules:
- Markdown editor (edit mode, raw text): 13px, weight 400, line-height 1.6 for readability during typing
- `CULTURE` section label in sidebar header: 12px (Label role), weight 400, letter-spacing 1.2, `colorScheme.onSurface.withValues(alpha: 0.5)` — the letter-spacing and alpha provide sufficient visual distinction from page titles without a 5th font size
- Broken-link `?` badge text: 12px (Label role), weight 600, `colorScheme.onError` foreground

Source: Matches `app.dart` `textTheme` — `bodyMedium` 13px, `bodySmall` 12px. Heading/Display sizes inferred from `headlineSmall` usage in empty states.

## Color

All colors reference `ColorScheme` tokens from `ThemeMode.dark` with seed `Color(0xFF5B8DEF)`.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Main content area background (Markdown render pane) |
| Secondary (30%) | `colorScheme.surfaceContainerLow` | Left tree sidebar background (matches `grammar_shell.dart`) |
| Secondary variant | `colorScheme.surfaceContainer` | Top nav bar background (matches `app_shell.dart`), back/forward button bar |
| Accent (10%) | `colorScheme.primary` | Selected tree node active indicator, internal link text color, `[[link]]` autocomplete highlight, back/forward active arrow |
| Selected node bg | `colorScheme.primaryContainer` | Selected sidebar tree tile background (matches `_SidebarTile` in `grammar_shell.dart`) |
| Selected node fg | `colorScheme.onPrimaryContainer` | Selected tree tile text + icon color |
| Destructive | `colorScheme.error` | Delete page confirmation dialog action, broken link `?` badge background |
| Muted text | `colorScheme.onSurface.withValues(alpha: 0.5)` | Timestamps, metadata, tree section header label |
| Divider | `colorScheme.outlineVariant` | Vertical divider between tree sidebar and content, section dividers |

Accent (`colorScheme.primary`) reserved for:
1. Selected tree node active left-border indicator (2px border-left)
2. Internal `[[wiki-link]]` rendered text color
3. Autocomplete dropdown selected item highlight
4. Back/forward navigation arrows (active/enabled state)

Broken-link `?` badge: `colorScheme.error` background, `colorScheme.onError` foreground — visually distinct but not aggressive (small icon, not inline red text).

Source: `lib/app.dart` seed color `0xFF5B8DEF`, `lib/shared/widgets/app_shell.dart` color usages, `lib/features/grammar/presentation/grammar_shell.dart` sidebar tile colors.

## Component Inventory

The following Flutter widgets are used. No new component libraries are added.

### CultureShell (new)
- Layout: `Row` — 240px `SizedBox` sidebar + `VerticalDivider` + `Expanded` content
- Sidebar background: `colorScheme.surfaceContainerLow`
- Section header: `Text('CULTURE', style: labelSmall)` at 12px, alpha 0.5, letter-spacing 1.2
- Pattern: mirrors `grammar_shell.dart` exactly

### PageTreeSidebar (new)
- Tree nodes rendered as `InkWell`-wrapped `Container` items (height 32px, horizontal padding 16px)
- Selected node: `colorScheme.primaryContainer` background, 2px left border in `colorScheme.primary`
- Tree indent: 16px per depth level via `Padding`
- Emoji/icon prefix: 18px `Text` widget before page title label (12px)
- Drag handle: 3-dot drag icon (`Icons.drag_indicator`, 16px, alpha 0.4) on hover/focus, rightmost position
- First 2 levels expanded by default (D-02); deeper nodes start with `ExpansionTile`-style collapsed state
- "Add page" button at sidebar bottom: `TextButton.icon` with `Icons.add`, label "New page", 13px

### MarkdownViewPane (new)
- Background: `colorScheme.surface`
- Rendered via `flutter_markdown` package — `MarkdownBody` widget with custom stylesheet
- Page header: row with optional emoji (18px), `Text` H1 at 20px weight 600, right-aligned timestamps at 12px alpha 0.4
- Section blocks separated by implicit whitespace; no visual dividers between sections
- Click target for section editing: entire block row (tap anywhere in rendered block to enter edit mode)

### SectionEditBlock (new)
- Switches between rendered `MarkdownBody` and raw `TextField` on tap
- `TextField` with `maxLines: null`, 13px, monospace, `colorScheme.surface` fill, `colorScheme.primary` focus border
- Syntax highlighting: `re_highlight` or `highlight` package for Markdown tokens (bold, headers, code) — apply via `TextSpan` spans
- "Done" affordance: pressing Escape or clicking outside the block exits edit mode and re-renders
- No formatting toolbar (D-07)

### WikiLinkAutocomplete (new)
- Triggered when user types `[[` inside an edit block
- `OverlayPortal` popup below cursor (matches `IpaKeyboardPopup` pattern from `lib/features/phonology/presentation/shared/ipa_keyboard/ipa_keyboard_popup.dart`)
- Popup dimensions: max 280px wide, max 240px tall, `surfaceContainer` background, 1px `outlineVariant` border, 6px border radius
- List items: 36px height, 12px label text, page emoji prefix
- Selected item: `primaryContainer` background
- Dismissed by: Escape, clicking outside, completing selection with Enter or Tab

### BrokenLinkBadge (new)
- Inline `InkWell` wrapping page title text + `?` superscript badge
- Badge: 16x16px circle, `colorScheme.error` background (alpha 0.8), `colorScheme.onError` foreground, 12px weight 600
- On tap: `AlertDialog` — "Page not found. Create '{{title}}'?" with Cancel / Create Page buttons

### HoverPreviewTooltip (new)
- `MouseRegion` on rendered internal links — `onEnter` triggers 400ms delay then shows overlay
- Overlay: max 320px wide, max 180px tall, `surfaceContainer` background, `outlineVariant` border 1px, border radius 8px, drop shadow elevation 4
- Content: page emoji + title at 13px weight 600, then first ~200 chars of page body at 12px alpha 0.7, clipped with `TextOverflow.ellipsis` / fade
- Dismissed on `onExit`

### BackForwardBar (new)
- `Row` of `IconButton` widgets: `Icons.arrow_back` and `Icons.arrow_forward`, 20px icons
- Container height 36px, `surfaceContainer` background, bottom `outlineVariant` divider 1px
- Disabled state: alpha 0.3, no `onPressed` (matches `Opacity(0.2)` pattern from morphology rule reorder arrows in Phase 2)
- Page history maintained as `List<int>` page ID stack per culture shell session

### PageContextMenu (new)
- Right-click or `...` overflow `IconButton` on tree tile hover
- `PopupMenuButton` with items: Rename, Set icon, Add child page, Delete Page
- Delete Page item: `colorScheme.error` text color

### DeletePageDialog (new)
- `AlertDialog` with title "Delete page?", body describing consequence (children orphaned or deleted)
- Two-button row: Cancel (text button) / Delete Page (filled button, `colorScheme.error` background)

## Interaction States

### Tree Sidebar
| State | Visual |
|-------|--------|
| Default | 12px label, alpha 0.85, no background |
| Hover | `surfaceContainer` background, drag handle appears |
| Selected | `primaryContainer` background, `onPrimaryContainer` text, 2px `primary` left-border |
| Drag active | `primary` alpha 0.1 background on drag target row, 2px `primary` top-border on drop zone |

### Section Edit Block
| State | Visual |
|-------|--------|
| Rendered (default) | `MarkdownBody` on `surface`, no border |
| Hover | Subtle `surfaceContainerLow` background tint, cursor changes to `text` |
| Edit active | `TextField` with `primary` focus border 1.5px, `surfaceContainerLow` fill |
| Edit unsaved | Dot indicator in section heading |
| Saving | No spinner — auto-save is instantaneous on focus-out |

### Internal Link
| State | Visual |
|-------|--------|
| Resolved | `primary` color text, underline on hover |
| Broken | `primary` color text + inline `?` badge in `error` color |
| Hover (resolved) | Underline + `HoverPreviewTooltip` after 400ms |
| Hover (broken) | Underline + cursor `pointer`, no preview |

## Layout

```
┌─────────────────────────────────────────────────────────────────┐
│ AppShell top bar (48px)                                          │
├────────────────────────────────────────────────────────────────-┤
│ ┌──────────────────┐ │ ┌──────────────────────────────────────┐ │
│ │  CULTURE (240px) │ │ │ [← →] Back/Forward bar (36px)       │ │
│ │  sidebar         │ │ ├──────────────────────────────────────┤ │
│ │                  │ │ │ Page header: emoji + H1 + timestamps │ │
│ │  ▼ World         │ │ ├──────────────────────────────────────┤ │
│ │    ▶ History     │ │ │                                      │ │
│ │    • Geography   │ │ │  Rendered Markdown content           │ │
│ │  ▼ Society       │ │ │  (section blocks, click to edit)     │ │
│ │    • Religion    │ │ │                                      │ │
│ │    • Politics    │ │ │                                      │ │
│ │                  │ │ │                                      │ │
│ │  [+ New page]    │ │ │                                      │ │
│ └──────────────────┘ │ └──────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

- Tree sidebar: 240px fixed, `surfaceContainerLow`
- Divider: 1px `outlineVariant` (matches all other shells)
- Content area: `Expanded`, `surface` background
- Back/forward bar: full width of content area, 36px height, `surfaceContainer`
- Page content: `SingleChildScrollView` with 24px horizontal padding, 16px vertical padding

**Primary focal point:** The page H1 title (20px, weight 600, `colorScheme.onSurface`) is the primary visual anchor of the content area. It is the largest and heaviest text element on screen and draws the user's eye immediately upon page navigation.
