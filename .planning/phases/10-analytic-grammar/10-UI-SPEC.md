## Spacing Scale

Declared values (must be multiples of 4). **Source:** Observed across `lib/features/grammar/presentation/` — all values are from this existing codebase.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap between inline elements (e.g. slot label + icon), chip inner padding |
| sm | 8px | Between label row and dropdown (`SizedBox(height: 8)`), sidebar item vertical margin (2px top/bottom → 4px total, exception noted below) |
| md | 16px | Page horizontal padding in sidebar header (`fromLTRB(16, 8, 4, 8)`), sidebar tile horizontal padding, section label left margin |
| lg | 24px | Between major sections on Typology page (`SizedBox(height: 24)`), page `padding: EdgeInsets.all(24)` for scrollable content pages |
| xl | 32px | Layout gaps between independent panels (content area edge spacing) |
| 2xl | 48px | Major section breaks within a page when grouping multiple POS sections |
| 3xl | 64px | Not used in grammar feature; available for page-level centering if empty state illustration needed |

**Exceptions:**
- Sidebar tile top/bottom margin: 2px (not on scale) — inherited from existing `_SidebarTile` pattern; do not change
- Inline icon sizes: 14px info icon, 16px help icon, 18px sidebar item icon — inherited; do not change
- Sidebar tile height: 40px fixed — inherited from existing `_SidebarTile` pattern

## Typography

**Source:** `lib/app.dart` `TextTheme` declaration, `lib/features/grammar/presentation/` usage.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (normal) | 1.5 | List item text, dropdown option labels, description copy |
| Label | 11px | 400 (normal), letter-spacing 0.5 | 1.2 | Section header labels in ALL CAPS (e.g. "GRAMMAR", "PARTICLES"), tooltip text |

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Main content area background, dialog backgrounds, page body |
| Secondary (30%) | `colorScheme.surfaceContainerLow` | Sidebar background (`GrammarShell._sidebarWidth` column material color) |
| Accent (10%) | `colorScheme.primaryContainer` | Selected sidebar tile background only |
| Accent text | `colorScheme.onPrimaryContainer` | Text/icon color on selected sidebar tile only |
| Destructive | `colorScheme.error` | Delete action icon color, destructive button foreground only |
| Body text | `colorScheme.onSurface` at 85% opacity | Normal list item text |
| Muted text | `colorScheme.onSurface` at 50% opacity | Section header caps, info icons, unselected sidebar icon |

**Accent reserved for:**
- Selected sidebar navigation item background (Particles tile, Constructions tile — same pattern as existing POS/Inflections/Typology tiles)
- Nothing else — primary/seed color is not used for buttons in this feature; use `FilledButton` (Material 3 default filled) for primary actions and `TextButton` for cancel

**60/30/10 split:**
- 60% dominant: content panel (right of sidebar divider) — `surface`
- 30% secondary: 200px sidebar panel — `surfaceContainerLow`
- 10% accent: selected sidebar tile only — `primaryContainer`

## Interaction Contracts

### Particles Page

- **Group by POS:** Particles list groups under collapsible POS section headers. Sections for POS categories that have no particles are hidden (not shown as empty). If no POS is defined yet, show the full empty state.
- **Add particle flow:** Tap "Add Particle" → `AlertDialog` opens with: IPA text field (IPA keyboard accessible), POS dropdown (from existing POS list), gloss tag autocomplete, meaning text field. Tap "Save" → dismiss dialog → particle appears in correct POS section. Tap "Cancel" → dismiss with no change.
- **Edit particle:** Tap particle row → same `AlertDialog` pre-filled with existing values.
- **Delete particle:** Tap delete icon in particle row → `AlertDialog` confirmation → confirmed delete removes from DB and list.
- **Unified search:** Particles created here appear in unified lexicon search automatically (no extra action needed — D-02 schema flag handles this).
- **Gloss tag autocomplete:** Shows filtered dropdown of ~45 Leipzig abbreviations as user types. User may type a custom tag not in the list and save it. Dropdown dismisses on selection or unfocus.

### Constructions Page

- **Selection:** Tapping a construction in the left list selects it and populates the right slot editor panel. First construction auto-selected on load.
- **Add slot:** Tap "Add Slot" → inline dialog or expansion with slot type selector (Gloss Tag / Part of Speech) and value field → tap "Add" → slot appears at end of list.
- **Reorder slots:** `ReorderableListView` with drag handles on each slot chip. Drag to reorder. On `onReorder` callback, persist all slot `ordering` values to DB.
- **Delete slot:** Trash icon on slot chip → immediate delete (no confirmation; slots are easily re-added).
- **Live preview:** Renders below slot editor. Updates reactively as slots change. Substitutes first matching closed-class word for each gloss-tag slot; first lexeme with matching POS for each open-class slot. Shows placeholder copy if no match.
- **Construction name edit:** Inline editable — tap the construction name in the detail panel to edit it in-place, or via rename icon. Auto-saves on unfocus.
- **Delete construction:** Trash icon on construction list item → `AlertDialog` confirmation.

### Typology Extension

- **Auto-save:** All four new dropdowns use the same `writeTypologyKey` upsert pattern as existing typology dropdowns. No save button.
- **Null state:** Dropdowns render with `null` / no selection until user chooses a value — same behavior as existing Alignment/Word Order/Modality dropdowns.
- **Tooltip:** Each new dropdown has an `Icons.info_outline` (14px, `colorScheme.onSurface` at 50% opacity) to the right of its label, same as existing typology sections.

### Sidebar Navigation

- **Tab order:** POS & Dimensions (0) → Inflections (1) → Particles (2) → Constructions (3) → Typology (4). This is D-13 locked order.
- **Selection highlight:** Active tab gets `colorScheme.primaryContainer` background with `colorScheme.onPrimaryContainer` text/icon.
- **No animation:** Tab switching is immediate navigation — no transition animation beyond Flutter's default `go_router` navigation.
