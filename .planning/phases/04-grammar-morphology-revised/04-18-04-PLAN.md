**Missing-assignment warning icons:**

After a dimension is marked intrinsic, words of that POS that haven't been assigned an intrinsic level should show a warning. The user wants to see this warning next to the words.

1. Create a new provider in `lexeme_providers.dart`:
   ```dart
   /// Returns the count of words for a given POS that are missing intrinsic
   /// level assignments for the given dimension.
   final missingIntrinsicAssignmentCountProvider = Provider.family<int, ({int posId, int dimId})>((ref, params) {
     final lexemesAsync = ref.watch(allLexemeListProvider);
     final lexemes = lexemesAsync.asData?.value ?? const <Lexeme>[];
     final posListAsync = ref.watch(posListProvider);
     final posList = posListAsync.asData?.value ?? const <PartsOfSpeechData>[];
     
     final posLexemes = lexemes.where((l) {
       final pos = posForLexeme(l, posList);
       return pos?.id == params.posId && !l.rootOnlyViaDerivations;
     });
     
     return posLexemes.where((l) {
       final levels = IntrinsicLevelsCodec.decode(l.intrinsicLevelsJson);
       return levels[params.dimId] == null;
     }).length;
   });
   ```

2. In `dimension_editor_panel.dart`, for dimensions marked as intrinsic, show a warning badge next to the dimension name when the count is > 0:
   - Watch `missingIntrinsicAssignmentCountProvider` for the dimension
   - If count > 0, show `Icon(Icons.warning_amber_outlined, size: 16, color: Colors.orange)` with a `Tooltip` saying `'{count} word(s) missing {dimName} assignment'`
   - Place this next to the dimension header or next to the intrinsic toggle

This is a read-only indicator — it doesn't block anything, just alerts the user to assign intrinsic levels to existing words.
