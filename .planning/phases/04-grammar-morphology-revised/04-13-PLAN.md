**Step 3 — Branch the click handler.** Replace the existing `openDialog` closure in `_ParadigmCellWidget.build` (around line 337):

```dart
void openDialog() {
  switch (clickMode) {
    case ParadigmClickMode.wordOverride:
      // D-54: preserve the existing per-word override flow in Lexicon host
      showDialog<void>(
        context: context,
        builder: (_) => CellOverrideDialog(
          lexemeId: lexemeId,
          featureSet: featureSet,
          currentCell: cell,
          existingOverride: override,
        ),
      );
      break;
    case ParadigmClickMode.ruleEditor:
      // D-51: open RuleEditorDialog with cell bindings pre-filled.
      // Both empty and filled cells open the dialog. For filled cells,
      // try to pass the existing rule as `existing:` so the dialog opens
      // in edit mode (the topmost rule in the chain is the best heuristic).
      db.MorphologicalRule? existingRule;
      if (cell case ParadigmFilled(:final ruleChain) when ruleChain.isNotEmpty) {
        // Look up the topmost rule by id from the morphologicalRuleListProvider
        final rules = ref.read(morphologicalRuleListProvider).asData?.value ?? const [];
        existingRule = rules.firstWhereOrNull((r) => r.id == ruleChain.first.id);
      }
      showDialog<void>(
        context: context,
        builder: (_) => RuleEditorDialog(
          kind: RuleKind.inflectional,
          existing: existingRule,
          preFilledBindings: existingRule == null ? featureSet : null,
        ),
      );
      break;
  }
}
```
