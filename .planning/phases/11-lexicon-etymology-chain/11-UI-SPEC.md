## Spacing Scale

Declared values — all existing Flutter spacings in this codebase use multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline label gaps, tight row padding (`EdgeInsets.only(top: 4)`) |
| sm | 8px | Chip padding, compact list items (`EdgeInsets.only(top: 8, bottom: 12)`) |
| md | 16px | Panel content padding (`EdgeInsets.all(16)`) |
| lg | 24px | Section breaks, content area padding (`EdgeInsets.all(24)`) |
| xl | 32px | Layout-level gaps (not used in detail panel; reserved) |
| 2xl | 48px | Major section breaks (not used in detail panel; reserved) |
| 3xl | 64px | Page-level (not used in detail panel; reserved) |

Exceptions:
- Tree node indentation: 20px per level (not a strict multiple of 8; chosen for visual tree density at monospace font)
- Connector line horizontal extent: 12px (half of 24px indent — visually bisects the level gap)
- Section header bottom gap: 8px (`SizedBox(height: 8)`)

Source: CONTEXT.md + codebase audit of `word_detail_panel.dart` and `derivation_tree_widget.dart`

## Color

All values are Material 3 ColorScheme tokens derived from seed colors in `app.dart`. Dark theme seed: `0xFF5B8DEF`; light theme seed: `0xFF1A56DB`.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Panel background, tree canvas background |
| Secondary (30%) | `colorScheme.surfaceContainerHigh` | Tree node chip/container background; current word highlight container |
| Accent (10%) | `colorScheme.primary` | Connector lines, navigable node icons, current-word border |
| Warning semantic | `Colors.amber` | Cycle detection marker ("⚠ cycle"), same pattern as exception override in `derivation_tree_widget.dart` |
| Destructive | `colorScheme.error` | Parent removal confirmation (× button on pill in searchable parent selector) |

Accent (`colorScheme.primary`) reserved for:
- Tree connector lines (vertical stem and horizontal branch lines)
- Navigation icon on tappable tree nodes (`Icons.arrow_upward` or `Icons.open_in_new`, size 14)
- Current word node border/left-border highlight
- Link icon in existing derivation tree rows (preserved pattern from `derivation_tree_widget.dart` line 548)

## Component Inventory

### 1. EtymologyChainSection

Replaces `WordDetailParentsSection` at `word_detail_panel.dart:675`.

**Structure:**
```
EtymologyChainSection
  Section header: "Etymology Chain" (13px, w600)
  AncestryTree (scrollable Column — ancestors above current word)
    AncestryNode × N (max 10 levels)
      indent: 20px × level
      ConnectorLines (vertical stem + horizontal branch, outlineVariant)
      NodeChip (tappable ActionChip)
        word form line (13px, w600, primary color if root node)
        meaning line (12px, w400, muted)
        edge label badge (11px, "via [rule name]" or "parent", muted)
    TruncationHint (if > 10 levels): "↑ N more ancestors" (11px, muted)
  CurrentWordNode (highlighted — surfaceContainerHigh background, primary left border 2px)
    word form line (13px, w600)
    meaning line (12px, w400, muted)
  ChildrenSection (immediate generation N+1 only)
    header: no separate header — downward branch visual continues from current node
    ChildNode × N (not recursive)
      indent: 20px (one level below current)
      ConnectorLines (same style)
      NodeChip (tappable ActionChip)
      edge label badge ("via [rule name]" or "parent")
  CycleMarker (if cycle detected): "⚠ cycle" chip, Colors.amber background
```

**Visibility rule:** Section hidden entirely when word has no parents AND no children (preserved from current `WordDetailParentsSection` behavior). Source: CONTEXT.md.

**Expansion state:** Expanded by default when parents or children exist. Source: CONTEXT.md.

### 3. NodeChip

Shared component used by both ancestry nodes and child nodes.

**States:**
- Default (tappable, `onNavigateToWord` set): `ActionChip` with `avatar: Icon(Icons.arrow_upward, size: 14, color: cs.primary)` for ancestors; `Icons.arrow_downward` for children
- Non-tappable (no `onNavigateToWord`): plain `Column` with word form + meaning text (same as current `_buildRuleDerivedParentRow` fallback)
- Current word: not a chip — plain highlighted container (no tap target)
- Cycle node: `ActionChip` with `Colors.amber` background, `Icons.warning_rounded` avatar

**Tap behavior:** Calls `onNavigateToWord(lexemeId)` — existing callback wired in `WordDetailPanel`.

## Interaction Contracts

### Tree Navigation
- Tapping any ancestor or child node chip calls `onNavigateToWord(id)`.
- Navigation replaces the detail panel content (existing router behavior — no modal).
- No keyboard focus trapping required for tree nodes (desktop, pointer-primary).

### Truncation
- If ancestry depth exceeds 10 levels, render the 10 nearest ancestors and show "↑ N more ancestors" text link at the top (11px, muted).
- Tapping "↑ N more ancestors": out of scope for Phase 11 (deferred per CONTEXT.md).

### Parent Selector (edit mode)
- `Autocomplete<Lexeme>` filters `allLexemeListProvider` client-side on romanization and meaning text. No server calls.
- Selecting a result adds the lexeme as a pill and clears the text field.
- Pressing × on a pill removes the parent link immediately (no confirmation — not destructive; undo is available by re-adding).
- Empty search shows no overlay (not a list-all dropdown).

### Cycle Detection
- During ancestry traversal, track visited IDs in a `Set<int>`.
- If a visited ID is encountered again, stop traversal at that node and render a "⚠ cycle" chip in `Colors.amber` instead of continuing. Source: CONTEXT.md.

### Bug Fix Interactions (in scope per CONTEXT.md)
- **Bug 1 (sequential derivation):** No direct UI change — engine computes correct derived form; derivation tree rows update automatically via existing `StreamProvider`.
- **Bug 2 (wrong parent displayed):** Fix resolves display automatically; no new UI affordance needed.
