    **Widget contract:**
    ```dart
    /// Searchable dropdown for selecting parent lexemes, replacing the
    /// non-scalable FilterChip wall (Phase 11 UX fix per CONTEXT.md).
    ///
    /// Shows selected parents as removable [ActionChip] pills below the
    /// search field. [Autocomplete] filters [allLexemeListProvider]
    /// client-side by romanization, IPA, and meaning (case-insensitive
    /// substring). Empty query shows no overlay.
    class SearchableParentSelector extends ConsumerStatefulWidget {
      const SearchableParentSelector({
        super.key,
        required this.selectedIds,
        required this.onChanged,
        required this.excludeId,
        this.enabled = true,
      });

      /// Currently selected parent lexeme IDs.
      final Set<int> selectedIds;

      /// Called with the new set of selected IDs when user adds/removes a parent.
      final ValueChanged<Set<int>> onChanged;

      /// Lexeme ID to exclude from autocomplete results (the word being edited).
      /// Pass -1 when creating a new word that has no ID yet.
      final int excludeId;

      /// Whether the selector is interactive.
      final bool enabled;
    }
    ```

    **State implementation details:**

    1. Hold a `TextEditingController _searchController` for the Autocomplete field. Dispose in `dispose()`.

    2. Use `Autocomplete<Lexeme>` (not `Autocomplete<String>`) with:
       - `displayStringForOption: (lx) => (lx.romanization?.isNotEmpty == true ? lx.romanization! : lx.ipa) + (lx.meaning != null ? ' — ${lx.meaning}' : '')`
       - `optionsBuilder: (textEditingValue)` that:
         - Returns `Iterable<Lexeme>.empty()` if text is empty
         - Reads `ref.read(allLexemeListProvider).asData?.value ?? const []`
         - Filters where `lx.id != widget.excludeId && !widget.selectedIds.contains(lx.id)` (excludes self and already-selected)
         - Filters by `query` (lowercase) against `lx.ipa`, `lx.romanization`, and `lx.meaning` (case-insensitive substring)
         - Returns max 20 results to avoid overlay overflow
       - `onSelected: (lx)` that calls `widget.onChanged({...widget.selectedIds, lx.id})` and clears the search text via `_searchController.clear()`
       - `fieldViewBuilder` that returns a `TextField` with:
         - `controller: controller` (from builder)
         - `focusNode: focusNode` (from builder)
         - `decoration: InputDecoration(hintText: 'Search words to add as parent\u2026', isDense: true, border: OutlineInputBorder())`
         - `style: theme.textTheme.bodyMedium?.copyWith(fontSize: 13)`
         - `enabled: widget.enabled`

    3. Below the Autocomplete, render selected pills as a `Wrap(spacing: 8, runSpacing: 8, children: [...])` of `ActionChip` widgets:
       - For each `id` in `widget.selectedIds`, look up the lexeme from `ref.watch(allLexemeListProvider)`
       - Each chip: `ActionChip(label: Text(displayLabel, style: theme.textTheme.labelSmall?.copyWith(fontSize: 11)), onDeleted: widget.enabled ? () => widget.onChanged({...widget.selectedIds}..remove(id)) : null, deleteButtonTooltipMessage: 'Remove parent link')`
       - Display label: `romanization ?? ipa` + ` — meaning` (if meaning exists)
       - If the lexeme can't be found in allLexemeListProvider (deleted), show `'Unknown (#$id)'`

    4. Wrap the Column containing Autocomplete + Wrap in a `Column(crossAxisAlignment: CrossAxisAlignment.start)` with `SizedBox(height: 8)` between search field and pills. Only show pills section if `selectedIds.isNotEmpty`.

    5. When `widget.enabled` is false, the Autocomplete text field is disabled and chip × buttons are null (no onDeleted).

    **Imports:** Use relative imports per project convention. Import `allLexemeListProvider` from `../../data/lexeme_providers.dart`. Import `Lexeme` from `../../../../db/app_database.dart`. Import `flutter_riverpod` for `ConsumerStatefulWidget`.
