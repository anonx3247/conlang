## IPA Keyboard Issues

1. **IPA keyboard unreachable at bottom** — when the text field is near the bottom of the screen, the popup keyboard extends below the visible area and can't be scrolled to. Needs position-aware placement (show above when near bottom).

2. **No IPA keyboard on new phoneme input dialog** — the add/edit phoneme dialog's IPA symbol field should have the IPA keyboard popup attached, currently it's missing.

3. **[w] phoneme missing from IPA keyboard** — the labial-velar approximant /w/ is not in the consonants list. It's classified as a labial-velar approximant (co-articulated) which may have been omitted from the standard pulmonic grid. Needs to be added as a special symbol or in the "Other" section.
