<task type="auto">
  <name>Task 2: Create macOS release build script and produce release zip</name>
  <files>scripts/build-release-macos.sh</files>
  <action>
Create `scripts/build-release-macos.sh` that:

1. Sets `set -euo pipefail`
2. Runs `flutter build macos --release`
3. Defines APP_NAME="Conlang Workbench" and VERSION from pubspec.yaml (grep version: pubspec.yaml, extract the part before +)
4. Creates a zip of the .app bundle: `cd build/macos/Build/Products/Release && zip -r -y "../../../../../Conlang-Workbench-${VERSION}-macos.zip" "Conlang Workbench.app"`
5. Prints the output path and file size
6. Make the script executable: `chmod +x scripts/build-release-macos.sh`

The `-y` flag preserves symlinks in the .app bundle (critical for macOS apps).

After writing the script, run it to produce the actual release zip. Verify the zip exists and is a reasonable size (should be >10MB for a Flutter app).
